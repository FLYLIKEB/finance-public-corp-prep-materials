# 10-03. 웹-네트워크 공격

> 학습 목적: 대표 공격 기법의 원리와 대응을 한 줄로 정리한다.
> 관련 기출: [05-12-보안-기출-모음](05-12-보안-기출-모음.md)
> 연결 핵심정리: [04-4-네트워크-프로토콜-보안](04-04-네트워크-프로토콜-보안.md)

## 핵심 개념

- 웹 공격은 입력값 검증 실패와 세션 취약점에서 자주 발생한다.
- 네트워크 공격은 가용성, 기밀성, 무결성을 침해한다.
- 공격명과 방어책을 함께 암기한다.


### 서술형 확장 개념

- 공격은 “원리 → 영향 → 방어책”으로 정리한다. XSS는 브라우저에서 스크립트가 실행되어 세션 탈취나 화면 변조를 일으키며, 출력 인코딩과 CSP로 방어한다. SQL Injection은 DB 쿼리 구조를 바꿔 인증 우회·정보 유출을 일으키며, prepared statement로 방어한다.
- CSRF는 사용자가 인증된 상태를 악용해 원치 않는 요청을 보내게 한다. CSRF token, SameSite cookie, 재인증으로 방어한다.
- SSRF는 서버가 내부망이나 클라우드 메타데이터 주소로 요청하게 만드는 공격이다. URL allowlist, 내부 주소 차단, 응답 검증이 필요하다.
- 파일 업로드 취약점은 웹쉘 실행, 악성 파일 저장, 경로 조작으로 이어질 수 있다. 확장자와 MIME 검증, 저장 경로 분리, 실행 권한 제거, 랜덤 파일명 사용이 기본이다.
- 방화벽은 네트워크/전송 계층 정책에 강하고, WAF는 HTTP 요청의 악성 패턴을 탐지한다. VPN은 통신 경로를 암호화하고 원격 접속 주체를 통제한다.

## 쉽게 이해하기

- 웹 공격은 사용자가 입력하는 값이나 웹 동작 방식을 악용하는 경우가 많다.
- 네트워크 공격은 통신 경로나 서버 자원을 공격해 정보 유출, 변조, 서비스 중단을 일으킨다.
- 공격을 외울 때는 “무엇을 노리는가: 기밀성, 무결성, 가용성”으로 분류하면 이해가 쉽다.
