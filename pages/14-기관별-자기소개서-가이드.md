# 14. 기관별 자기소개서 가이드

금융공기업 자기소개서는 같은 경험이라도 기관의 역할과 시스템 특성에 맞게 재해석해야 설득력이 생깁니다. 이 장은 코스콤·산업은행·금융결제원·예탁결제원·한국거래소 지원 시 강조할 역량과 문항별 연결 방식을 정리합니다.

## 기관별 인재상·강조 포인트 비교표

| 기관 | 핵심 역할 | 자소서 핵심 키워드 | IT 경험 연결 포인트 | 피해야 할 표현 |
|---|---|---|---|---|
| 코스콤 | 자본시장 IT 인프라·거래 시스템 | 고가용성, 저지연, 시장 안정 | 장애 대응, 성능 개선, 보안 운영 | 단순 SI 개발사처럼 표현 |
| 산업은행 | 정책금융·산업 육성 | 공공성, 산업 이해, 글로벌 역량 | 데이터 기반 의사결정, 리스크 관리 시스템 | 일반 은행 영업 중심 서술 |
| 금융결제원 | 지급결제 공동망·인증 인프라 | 안정성, 보안, 표준화 | 대규모 트래픽, API, 인증·암호화 | 편의성만 강조하고 안정성 누락 |
| 예탁결제원 | 증권 예탁·결제·권리관리 | 정확성, 신뢰, 자본시장 이해 | 배치/정산, 데이터 무결성, 운영 자동화 | 거래소와 역할 혼동 |
| 한국거래소 | 시장 운영·감시·상장 인프라 | 공정성, 투명성, 데이터 분석 | 실시간 시스템, 이상거래 탐지, 분석 | 투자 수익 관점 강조 |

## 공통 작성 원칙

1. **기관 미션을 먼저 정의**하고, 그 미션을 기술적으로 지탱하는 요소를 찾습니다.
2. 경험은 `문제 상황 → 기술적 판단 → 정량 성과 → 기관 기여` 순서로 씁니다.
3. 금융IT는 편의성보다 **신뢰성·무결성·보안·가용성**을 우선합니다.
4. 같은 프로젝트도 기관별로 강조점을 바꿉니다. 예를 들어 성능 개선 경험은 코스콤에서는 저지연 거래, 금융결제원에서는 결제망 안정성, 산업은행에서는 정책금융 데이터 처리 효율로 연결합니다.
