# 09-01. 선형 자료구조

> 학습 목적: 배열, 리스트, 스택, 큐의 사용 상황을 구분한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-5-자료구조-알고리즘-DB-금융IT](04-05-자료구조-알고리즘-DB-금융IT.md)

## 핵심 개념

- 선형 자료구조는 데이터가 순서대로 연결된다. 즉 각 원소가 1차원적 순서를 가진다.
- 배열(Array)은 인덱스 기반 랜덤 접근(Random access)이 가능해 임의 위치 접근이 O(1)이다.
- 연결리스트(Linked List)는 노드 간 포인터로 구성되어 삽입과 삭제가 O(1)인 경우가 있다(해당 위치의 포인터를 알고 있을 때).
- 스택(Stack)은 LIFO(Last-In-First-Out) 구조, 큐(Queue)는 FIFO(First-In-First-Out) 구조이다.
- 구현 방식(배열 기반 vs 연결 기반)에 따라 시간/공간 복잡도와 메모리 특성이 달라진다.

## 쉽게 이해하기

- 선형 자료구조는 데이터가 한 줄로 서 있는 구조다. 줄을 선 사람들처럼 앞뒤 관계가 있다.
- 배열은 번호가 붙은 사물함처럼 바로 찾아가기 쉽다. 인덱스를 이용하면 곧바로 접근할 수 있다.
- 연결리스트는 각 사람이 다음 사람을 가리키는 줄과 비슷하다. 중간에 사람을 넣거나 뺄 때 줄을 다시 연결하면 된다.
- 자료구조 선택은 “자주 찾는가(탐색 비용), 자주 넣고 빼는가(삽입/삭제 비용), 크기가 고정인가 동적인가”로 판단한다.

## 선형 자료구조별 요약

### 배열 (Array)
- 구조: 연속된 메모리 블록에 원소들이 인접하게 저장.
- 장점: 인덱스 접근 O(1), 캐시 친화적(연속 메모리로 인해 현저히 빠름).
- 단점: 크기 고정(정적 배열)일 경우 확장 비용, 중간 삽입/삭제 시 이동 비용 O(n).
- 사용 경우: 인덱스 기반 빈번한 접근, 고정 크기 데이터, 정렬된 데이터의 이진 탐색 등.

예시 연산(의사코드):

```text
# 접근
x = A[i]        # O(1)

# 삽입(임의 위치)
for k from n-1 down to i:
    A[k+1] = A[k]
A[i] = value    # O(n)
```

### 연결리스트 (Linked List)
- 구조: 각 노드가 데이터와 다음 노드(및 필요한 경우 이전 노드)에 대한 포인터를 가짐.
- 단일 연결리스트: 각 노드가 다음 포인터만 가짐. 양방향(이중) 리스트: prev, next 포인터 보유.
- 장점: 중간 삽입/삭제가 포인터 재연결로 O(1) (단, 위치 탐색 비용 제외).
- 단점: 임의 접근 O(n), 포인터 저장으로 추가 메모리 사용, 캐시 비우호적.
- 사용 경우: 빈번한 삽입/삭제, 크기 변화가 크고 임의 접근이 드문 경우.

예시 연산(의사코드):

```text
# 노드 삽입(현재 노드를 알고 있을 때)
new.next = curr.next
curr.next = new    # O(1)

# 탐색
p = head
i = 0
while p != null and i < idx:
    p = p.next
    i += 1          # O(n)
```

### 스택 (Stack)
- 구조: LIFO. push(삽입), pop(삭제), peek(탐색) 연산을 제공.
- 배열 기반 스택: push/pop O(1) (확장 비용 제외). 연결리스트 기반 스택: O(1).
- 사용 경우: 재귀를 반복으로 바꿀 때, 괄호 매칭, DFS 구현, 실행 취소 기능 등.

예시(배열 기반):

```text
push(x):
    if top == capacity: resize()
    A[top] = x
    top += 1

pop():
    if top == 0: error
    top -= 1
    return A[top]
```

### 큐 (Queue)
- 구조: FIFO. enqueue(삽입), dequeue(삭제), front(탐색) 연산.
- 단순 배열 기반 큐는 앞에서 삭제 시 O(n) 이동 필요 — 원형 큐(circular buffer)로 해결 가능.
- 연결리스트 기반 큐는 head/tail 포인터로 O(1) enqueue/dequeue.
- 사용 경우: 작업 스케줄링, BFS(너비 우선 탐색), 프린터 큐 등.

예시(원형 큐):

```text
enqueue(x):
    if (rear + 1) % capacity == front: resize()
    A[rear] = x
    rear = (rear + 1) % capacity

dequeue():
    if front == rear: error
    x = A[front]
    front = (front + 1) % capacity
    return x
```

## 시간/공간 복잡도 요약

| 자료구조 | 접근 | 검색 | 삽입 | 삭제 | 추가 메모리 |
|---|---:|---:|---:|---:|---:|
| 배열 (임의 위치) | O(1) | O(n) | O(n) | O(n) | 낮음 (연속)
| 연결리스트 (단일) | O(n) | O(n) | O(1)* | O(1)* | 노드 포인터 비용
| 스택 (배열/리스트) | O(1) | O(n) | O(1) | O(1) | 구현에 따라 다름
| 큐 (원형/리스트) | O(1) | O(n) | O(1) | O(1) | 구현에 따라 다름

*참고: 삽입/삭제가 O(1)인 것은 해당 위치의 노드를 이미 알고 있을 때(포인터를 알고 있을 때)입니다. 위치를 찾는 비용은 별도 O(n)입니다.

- [ ] 배열에서 임의 삽입/삭제의 시간 복잡도와 그 이유를 말할 수 있다.

- [ ] 스택/큐의 LIFO/FIFO 개념을 예제(괄호 검사, BFS/DFS)로 설명할 수 있다.
- [ ] 원형 큐 구현 아이디어와 포인터(또는 인덱스) 증가 방식을 설명할 수 있다.
- [ ] 각 자료구조의 장단점과 실제 사용 사례를 비교할 수 있다.

## 자주 나오는 문제 유형 (기출 연계)

1) 배열 또는 연결리스트 중 어떤 자료구조를 선택할지 판단하는 문제
   - 포인트: 빈번한 임의 접근이면 배열, 빈번한 중간 삽입/삭제이면 연결리스트.

2) 스택을 이용한 괄호 검사
   - 풀이요지: 여는 괄호는 push, 닫는 괄호는 pop하여 매칭 확인. 스택 비어있음/마지막 요소 불일치 시 오류.

3) 큐를 이용한 BFS 경로 탐색
   - 풀이요지: 시작 노드를 enqueue, 방문 표시 후 큐에서 꺼내 인접 노드 enqueue.

4) 원형 큐 관련 인덱스 계산/오버플로우 처리 문제
   - 풀이요지: (rear + 1) % capacity 형태로 포인터 이동, full/empty 구분에 주의.

5) 연결리스트에서 k번째 뒤의 노드 찾기(두 포인터 기법)
   - 풀이요지: fast 포인터를 k만큼 먼저 이동 후 slow와 함께 이동하여 fast가 끝에 닿으면 slow가 대상.

## 연습 문제 (짧은 해설 포함)

1) 배열 A에 대해 A[1000000]에 접근하는 비용은? 이유는?
   - 정답: O(1). 인덱스를 이용한 직접 접근이기 때문.

2) 단일 연결리스트에서 첫 번째 노드 직후에 노드를 삽입하는 시간 복잡도는?
   - 정답: O(1). 첫 노드 포인터만 바꾸면 되기 때문.

3) 스택으로 괄호 문자열 "([]){}" 검증하는 절차를 서술하라.
   - 해설: 여는 괄호는 스택에 push. 닫는 괄호가 나오면 스택 top과 매칭되는지 확인 후 pop. 끝까지 매칭되면 유효.

4) 큐에서 원형 버퍼를 사용할 때 full과 empty를 구분하는 방법은?
   - 해설: 하나의 슬롯을 비워두는 방법(즉 (rear+1) % capacity == front이면 full), 또는 별도 변수 size를 유지하여 size == 0이면 empty, size == capacity이면 full.

## 자주 하는 실수와 팁

- 실수: 연결리스트의 삽입이 항상 O(1)이라고 설명하는 실수 — 위치 검색 비용을 고려해야 함.
- 팁: 문제에서 "임의 접근이 필요"라는 표현이 있으면 배열을 떠올리고, "빈번한 삽입/삭제"라는 표현이 있으면 리스트를 떠올린다.
- 팁: 스택/큐는 추상 자료형(ADT) 개념으로 연산의 의미에 집중하고, 구현은 배열/리스트 중 선택 가능하다는 점을 기억하라.
