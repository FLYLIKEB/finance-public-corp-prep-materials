## 전통적 머신러닝 모델

- **Linear regression**: 연속값 예측의 기본 모델로 해석이 쉽다.
- **Logistic regression**: 이진 분류 베이스라인으로 자주 쓰이며 계수 해석이 비교적 쉽다.
- **Decision tree**: 규칙 기반이라 직관적이지만 깊어질수록 과적합되기 쉽다.
- **Random forest**: 여러 트리를 결합해 분산을 줄인다.
- **Gradient boosting**: XGBoost, LightGBM 계열처럼 금융 데이터에서 강한 성능을 내는 경우가 많다.
- **SVM**: 마진 최대화 기반 모델로 고차원 데이터에 쓸 수 있지만 대규모 데이터에서는 비용이 크다.

## 비지도 학습과 차원 축소

- **K-means**는 중심점 기반 군집화라 빠르지만 k 선택과 스케일에 민감하다.
- **PCA**는 분산이 큰 축을 찾아 차원을 줄이며 시각화와 노이즈 감소에 유용하다.
- **이상치 탐지**는 Isolation Forest, LOF 같은 방식으로 초기 필터링에 활용될 수 있다.

## 딥러닝 핵심

- 신경망은 입력층, 은닉층, 출력층과 가중치, 활성화 함수로 구성된다.
- 학습은 손실 함수, 역전파, 경사하강법으로 이뤄진다.
- **CNN**은 이미지·격자형 데이터에 강하고, **RNN/LSTM**은 순차 데이터 처리에 쓰였으며, **Transformer**는 어텐션으로 긴 문맥 관계를 잘 다룬다.
- 딥러닝은 복잡한 비선형 문제에 강하지만 데이터·연산 자원·설명가능성 요구가 크다.

## 모델 선택 기준

| 기준 | 단순 모델 선호 상황 | 복잡 모델 선호 상황 |
| --- | --- | --- |
| 데이터 크기 | 작거나 구조화 중심 | 매우 크거나 비정형 포함 |
| 설명가능성 | 규제 대응이 핵심 | 성능 우선 과업 |
| 추론 속도 | 실시간·경량 추론 필요 | 배치 처리 허용 |
| 피처 구조 | 사람이 정의한 피처가 강함 | 표현 학습이 필요 |

## 면접 포인트

- 실제 답안은 “로지스틱 회귀로 베이스라인을 잡고, 트리 기반 모델로 성능을 비교하며, 필요 시 딥러닝을 검토한다”처럼 단계적으로 설명하면 안정적이다.
- 금융권에서는 성능이 조금 높더라도 설명가능성과 승인 절차 부담이 커지면 복잡 모델을 바로 채택하지 않을 수 있다.
- Attention, CNN, 역전파 같은 개념은 구조를 외우기보다 어떤 데이터에서 왜 쓰는지로 설명하는 편이 낫다.
