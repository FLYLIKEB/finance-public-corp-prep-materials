```
### 238. 어떤 병원 데이터베이스에서 다음과 같은 속성을 가진 릴레이션 R이 존재한다.
```

- 환자번호
- 환자이름
- 진료과코드
- 진료과이름
- 담당의사

다음과 같은 함수 종속이 성립한다.

환자번호 → 환자이름
진료과코드 → 진료과이름, 담당의사
(환자번호, 진료과코드) → 진료기록번호

**답:** 같은 환자번호는 항상 동일한 환자를 의미하므로, 환자번호가 주어지면 환자이름은 하나로 정해진다. 하나의

진료기록번호가 결정된다.

후보키는 (환자번호, 진료과코드)이다.

(1-2) 해당 릴레이션에서 발생 가능한 이상을 설명하고, 제3정규형(3NF)을 만족하도록 변경하시오

**답:** 해당 릴레이션은 환자번호 → 환자이름, 진료과코드 → 진료과이름, 담당의사와 같은 함수 종속을 가지며,
후보키인 (환자번호, 진료과코드)에 대해 일부 속성이 부분적으로 종속되는 부분 함수 종속이 존재한다.

이로 인해 다음과 같은 이상이 발생할 수 있다.
- 삽입 이상: 환자 정보나 진료과 정보만 단독으로 저장할 수 없으며, 불필요한 값까지 함께 입력해야 한다.
- 삭제 이상: 특정 환자의 진료기록을 삭제할 경우, 해당 환자 또는 진료과에 대한 정보까지 함께 삭제될 수 있다.
- 갱신 이상: 진료과이름이나 담당의사가 변경될 경우 여러 튜플을 수정해야 하며, 일부만 수정 시 데이터
불일치가 발생할 수 있다.

이를 해결하기 위해 다음과 같이 분해하여 3NF를 만족시킨다.

- R1(환자번호, 환자이름)

- R2(진료과코드, 진료과이름, 담당의사)

- R3(환자번호, 진료과코드, 진료기록번호)

### 239. IP 주소 192.168.10.0/24가 주어졌다. 다음 조건을 만족하도록 서브넷을 설계하시오. (약술)
- 가능한 한 많은 서브넷으로 분할할 것
- 각 서브넷은 최소 16개의 호스트를 수용해야 한다

### 2. 생성 가능한 서브넷 수

**답:**

### 1. 서브넷 마스크 : 255.255.255.224/27
- 최소 16개의 호스트를 수용해야 하므로, 각 서브넷에서 사용할 수 있는 호스트 수를 고려해야 한다.
          IP 주소에서는 네트워크 주소와 브로드캐스트 주소를 제외해야 하므로, 실제로는 16개보다 많은 주소
          공간이 필요하다. 이에 따라 2h−2≥16을 만족하는 최소의 h를 구하면, h=4일 때는 14개로 부족하고,
          h=5일 때는 30개로 조건을 만족한다. 따라서 각 서브넷은 최소 5비트의 호스트 비트를 가져야 한다.

          주어진 네트워크는 /24이므로 총 8비트의 호스트 영역을 가지고 있는데, 이 중 5비트를 호스트로
          사용하고 남은 3비트는 서브넷을 나누는 데 사용하게 된다.
          따라서 네트워크 비트는 기존 24비트에서 3비트가 증가한 27비트가 되며, 최종 서브넷 마스크는
          /27이다. 이를 10진수로 표현하면 255.255.255.224가 된다.

### 2. 생성 가능한 서브넷 수 : 8개
- /24에서 /27로 확장되면서 3비트가 서브넷 비트로 사용된다. 따라서 생성 가능한 서브넷 수는 23=8개다.

### 3. 각 서브넷당 최대 호스트 수 : 30개
- 호스트 비트가 5개이므로 각 서브넷당 IP 개수는 25=32개이다. 이 중 네트워크 주소와 브로드캐스트
          주소 2개를 제외하면 사용 가능한 최대 호스트 수는 30개이다.
