## 약어 풀이

- ACID: Atomicity·Consistency·Isolation·Durability, 원자성·일관성·격리성·지속성
- BFS: Breadth-First Search, 너비 우선 탐색
- DFS: Depth-First Search, 깊이 우선 탐색
- DNS: Domain Name System, 도메인 이름 시스템
- GROUP BY: SQL 그룹화 절
- CPU: Central Processing Unit, 중앙처리장치
- CS: Computer Science, 컴퓨터과학
- HTTP: HyperText Transfer Protocol, 하이퍼텍스트 전송 프로토콜
- IP: Internet Protocol, 인터넷 프로토콜
- JOIN: SQL 테이블 결합 연산
- NCS: National Competency Standards, 국가직무능력표준
- OSI: Open Systems Interconnection, 개방형 시스템 상호연결
- SQL: Structured Query Language, 구조화 질의어
- TCP: Transmission Control Protocol, 전송 제어 프로토콜
- TLS: Transport Layer Security, 전송 계층 보안
- UDP: User Datagram Protocol, 사용자 데이터그램 프로토콜
