# 09-04. 동적계획법과 재귀

> 학습 목적: 중복 부분 문제와 재귀 종료 조건을 정리한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-5-자료구조-알고리즘-DB-금융IT](04-05-자료구조-알고리즘-DB-금융IT.md)

## 핵심 개념

- 재귀는 자기 자신을 호출하는 방식이다.
- 종료 조건이 없으면 무한 호출이 발생한다.
- DP는 중복 계산을 저장해 줄인다.

## 쉽게 이해하기

- 재귀는 큰 문제를 같은 모양의 작은 문제로 나눠 자기 자신을 다시 부르는 방식이다.

![피보나치 재귀 호출 트리](https://raw.githubusercontent.com/FLYLIKEB/finance-public-corp-prep-materials/main/assets/downloaded-visual-aids/fibonacci-recursion.png)
> 그림: 피보나치 재귀 호출 트리 기반으로 재귀 호출 구조 개념을 시각적으로 확인한다.
> 출처: https://commons.wikimedia.org/wiki/File:Fibonacci.png
- 동적계획법은 이미 계산한 작은 문제의 답을 저장해 다시 계산하지 않는 방식이다.
- 피보나치 수열처럼 같은 계산이 반복되는 문제에서 DP 효과가 크다.

![동적계획법과 재귀](https://raw.githubusercontent.com/FLYLIKEB/finance-public-corp-prep-materials/main/assets/downloaded-visual-aids/fibonacci-dp.png)
> 그림: 피보나치 동적계획법 중복 부분 문제 기반으로 동적계획법과 재귀 개념을 시각적으로 확인한다.
> 출처: https://commons.wikimedia.org/wiki/File:Fibonacci_dynamic_programming.svg
