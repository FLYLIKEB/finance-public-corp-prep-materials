# 09-04. 동적계획법과 재귀

> 학습 목적: 중복 부분 문제와 재귀 종료 조건을 정리한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-5-자료구조-알고리즘-DB-금융IT](04-05-자료구조-알고리즘-DB-금융IT.md)

## 핵심 개념

- 재귀는 자기 자신을 호출하는 방식이다.
- 종료 조건이 없으면 무한 호출이 발생한다.
- DP는 중복 계산을 저장해 줄인다.


### 서술형 확장 개념

- DP는 최적 부분 구조와 중복 부분 문제가 있을 때 사용한다. Memoization은 재귀 결과를 저장하는 top-down 방식이고, Tabulation은 작은 상태부터 표를 채우는 bottom-up 방식이다.
- 0/1 Knapsack은 `dp[i][w] = i번째 물건까지 고려했을 때 무게 w에서의 최대 가치`처럼 상태를 정의한다. LIS는 각 위치를 마지막 원소로 하는 최장 길이, LCS는 두 문자열 prefix 길이를 상태로 둔다.
- 재귀 코드 추적은 호출 스택과 반환값을 함께 적어야 한다. 종료 조건, 호출 순서, 전역 변수 갱신 시점이 출력 결과를 바꾸는 대표 함정이다.

```text
fib(4)
= fib(3) + fib(2)
= (fib(2)+fib(1)) + (fib(1)+fib(0))
```

위처럼 같은 `fib(2)`가 반복 계산되므로 저장하면 시간복잡도가 지수에서 O(n)으로 줄어든다.
