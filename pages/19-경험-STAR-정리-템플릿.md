# 19. 경험 STAR 정리 템플릿

자기소개서 소재는 면접에서 다시 질문으로 돌아옵니다. 같은 경험을 Situation, Task, Action, Result로 구조화하고 기관 미션에 맞게 재구성해두면 답변의 일관성과 설득력이 높아집니다.

## STAR 프레임워크

| 요소 | 작성 질문 | 답변 기준 |
|---|---|---|
| Situation | 어떤 상황이었나? | 배경과 제약을 2~3문장으로 설명 |
| Task | 내가 맡은 과제는 무엇인가? | 역할과 목표를 명확히 구분 |
| Action | 어떤 행동을 했나? | 판단 과정, 기술 선택, 협업 방식 |
| Result | 결과는 무엇인가? | 수치, 배운 점, 재발 방지 |

## 경험 소재 목록

- 프로젝트: 성능 개선, 신규 기능, 데이터 분석, 자동화
- 협업: 요구사항 조율, 갈등 해결, 문서화, 코드리뷰
- 장애 대응: 원인 분석, 임시 조치, 재발 방지
- 성과: 처리 시간 단축, 오류율 감소, 사용자 만족도 개선
- 학습: 새로운 기술 습득, 자격증, 스터디 운영

## 3단계 변환 예시

1. 기술 경험: API 응답 속도를 개선했다.
2. 직무 연결: 대규모 금융 서비스에서 병목을 찾고 안정적으로 개선하는 역량이다.
3. 기관 미션 연결: 금융결제원에서는 결제 인프라의 응답성과 안정성을 높이는 데 기여할 수 있다.

## 기관 인재상별 강조 포인트

| 기관 | 같은 경험의 강조 방향 |
|---|---|
| 코스콤 | 자본시장 시스템의 저지연·고가용성 |
| 산업은행 | 정책금융 업무 효율화와 데이터 기반 판단 |
| 금융결제원 | 결제망 안정성, 보안, 장애 예방 |
| 예탁결제원 | 데이터 정합성, 배치 검증, 운영 책임감 |
| 한국거래소 | 시장 공정성, 실시간 데이터 분석 |

## 점검 질문

- 내가 한 행동과 팀이 한 일이 구분되는가?
- 결과가 숫자나 관찰 가능한 변화로 표현되는가?
- 기관 이름만 바꾼 답변이 아니라 기관 미션과 실제로 연결되는가?

## 약어 풀이

- API: Application Programming Interface, 응용 프로그램 인터페이스
- STAR: Situation·Task·Action·Result, 상황·과제·행동·결과 경험 정리법
