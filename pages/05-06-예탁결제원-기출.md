## 예탁결제원

### 165. 정규화 문제
**답(AI답변):** 데이터 중복과 이상 현상을 줄이기 위해 릴레이션을 분해하는 과정이다. 부분/이행 종속 제거가 핵심이다.
### 166. 2PL 문제
**답(AI답변):** 2PL은 확장 단계에서 잠금 획득만, 축소 단계에서 잠금 해제만 허용해 직렬 가능성을 보장한다.
### 167. 해싱 문제
**답(AI답변):** 해싱은 키를 해시함수로 주소/버킷에 매핑해 빠른 검색을 수행하는 기법이다. 충돌은 체이닝/개방주소법으로 처리한다.
### 168. DMA 문제
**답(AI답변):** DMA는 CPU 개입을 줄이고 입출력 장치와 메모리가 직접 데이터를 전송하게 하는 방식이다.
### 169. 최대힙 문제
**답(AI답변):** 최대힙은 부모 노드 값이 자식 노드 값보다 크거나 같은 완전 이진트리다.
### 170. 하노이탑 문제
**답(AI답변):** n개 원반의 최소 이동 횟수는 2^n - 1이며 재귀적으로 n-1개 이동, 큰 원반 이동, n-1개 이동 순서다.
### 171. 공개키 알고리즘 문제
**답(AI답변):** 문제의 선지/도표가 원문에 충분히 남아 있지 않아 단정형 정답은 제한적이다. 해당 주제의 핵심 개념과 대표 공식·특징을 기준으로 풀이해야 한다.
### 172. 애자일 프로세스 문제
**답(AI답변):** 애자일은 짧은 반복, 고객 피드백, 변화 수용을 중시한다. 폭포수처럼 모든 단계를 순차 고정하지 않는다.
### 173. DBMS 특징 문제
**답(AI답변):** 문제의 선지/도표가 원문에 충분히 남아 있지 않아 단정형 정답은 제한적이다. 해당 주제의 핵심 개념과 대표 공식·특징을 기준으로 풀이해야 한다.
### 174. 다익스트라 알고리즘 문제
**답(AI답변):** 다익스트라는 음수 가중치가 없는 그래프에서 시작 정점부터 각 정점까지의 최단거리를 구하는 알고리즘이다.
### 175. TCP와 UDP에 대한 설명으로 옳지 않은 것은?
**답(AI답변):** TCP는 연결형·신뢰성·순서 보장, UDP는 비연결형·비신뢰성·빠른 전송이 특징이다.
### 176. 스머프어택 뜻
**답(AI답변):** 스머프 공격은 ICMP Echo 요청을 브로드캐스트 주소로 보내고 출발지 IP를 피해자로 위조해 트래픽을 집중시키는 DDoS 공격이다.
### 177. 파이썬 코드 주면서 출력값 문제
**답(AI답변):** 문제의 선지/도표가 원문에 충분히 남아 있지 않아 단정형 정답은 제한적이다. 해당 주제의 핵심 개념과 대표 공식·특징을 기준으로 풀이해야 한다.
### 178. HRN 계산문제
**답(AI답변):** HRN 우선순위 = (대기시간 + 서비스시간) / 서비스시간. 값이 큰 작업을 먼저 처리한다.
### 179. 재귀함수 루프횟수 구하는 문제
**답(AI답변):** 재귀 호출 횟수는 종료 조건에 도달할 때까지의 호출 트리/점화식을 세어 계산한다.
### 180. 스키마종류-개념 문제

## 약어 풀이

- CPU: Central Processing Unit, 중앙처리장치

- HRN: Highest Response-ratio Next, 최고 응답률 우선
- IT: Information Technology, 정보기술
- TCP: Transmission Control Protocol, 전송 제어 프로토콜
