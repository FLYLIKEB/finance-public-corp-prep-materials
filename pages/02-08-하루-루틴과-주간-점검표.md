## 프로그래머스 자료구조·알고리즘 풀이 계획

한국은행 대비 목적은 “온라인 코테 만점”이 아니라 필기에서 코드 조각, 복잡도, 알고리즘 선택 근거를 설명하는 힘을 만드는 것이다. 따라서 [프로그래머스 코딩테스트 고득점 Kit](https://school.programmers.co.kr/learn/challenges?tab=algorithm_practice_kit)를 중심으로 **필수 30문제 + 보강 15문제**, 총 **45문제 내외**를 4~6주에 나누어 푼다.

### 1단계: 필수 30문제

| 유형 | 목표 문제 수 | 우선 문제 | 목표 |
|---|---:|---|---|
| 해시 | 4~5 | 완주하지 못한 선수, 폰켓몬, 전화번호 목록, 의상, 베스트앨범 | key-value 집계, 중복 처리, 정렬 결합 |
| 스택/큐 | 5~6 | 같은 숫자는 싫어, 기능개발, 올바른 괄호, 프로세스, 다리를 지나는 트럭, 주식가격 | LIFO/FIFO, 시뮬레이션, 단조 스택 감각 |
| 힙 | 3 | 더 맵게, 디스크 컨트롤러, 이중우선순위큐 | 우선순위 큐 사용 조건 판단 |
| 정렬 | 3 | K번째수, 가장 큰 수, H-Index | 정렬 기준 설계, 비교 함수 감각 |
| 완전탐색 | 4~5 | 최소직사각형, 모의고사, 소수 찾기, 카펫, 피로도 | 경우의 수 생성, 순열/조합, 가지치기 |
| DFS/BFS·그래프 | 5~6 | 타겟 넘버, 네트워크, 게임 맵 최단거리, 단어 변환, 여행경로, 가장 먼 노드 | 재귀/큐 탐색, 방문 처리, 최단거리 |
| DP·이분탐색 | 4~5 | 정수 삼각형, 등굣길, N으로 표현, 입국심사, 징검다리 | 점화식, 파라메트릭 서치 기본 |

### 2단계: 보강 15문제

필수 30문제를 풀고 약한 유형만 추가한다. 한은 필기 관점에서는 모든 고난도 문제를 끝까지 파기보다, 풀이 설명 가능성을 우선한다.

- 스택/큐가 약하면: 주식가격, 큰 수 만들기, 과제 진행하기류의 “상태를 쌓아두는” 문제를 추가한다.
- 그래프가 약하면: 전력망을 둘로 나누기, 순위, 가장 먼 노드처럼 그래프 모델링이 필요한 문제를 추가한다.
- DP가 약하면: 정수 삼각형 → 등굣길 → N으로 표현 순서로 풀고, 도둑질·사칙연산 같은 Level 4는 시간이 남을 때만 본다.
- 이분탐색은 입국심사를 먼저 완전히 설명 가능하게 만들고, 징검다리는 보강용으로 둔다.

### 풀이 후 기록 양식

각 문제는 정답 제출보다 다음 4줄 기록을 남기는 것이 더 중요하다.

1. 핵심 아이디어: 어떤 상태를 어떤 순서로 처리했는가?
2. 자료구조 선택: 왜 배열/해시/스택/큐/힙/그래프를 썼는가?
3. 복잡도: 시간복잡도와 공간복잡도는 얼마인가?
4. 필기 전환: 코드 없이 의사코드나 5~7문장 서술형으로 설명하면 어떻게 쓰는가?

## 7. 주간 점검표

매주 일요일 체크.

- [ ] NotebookLM 과목별 생성 문제 풀이 수 기록
- [ ] 한은 기출은 9월 전까지 직접 풀이하지 않고 스타일 참고 소스 상태 유지
- [ ] 서술형 답안 5문항 이상 작성
- [ ] 전공논술 1편 이상 작성
- [ ] 오답노트 업데이트
- [ ] NCS 2세트 이상
- [ ] SQL/코딩 유지: 프로그래머스 7~10문제 또는 오답 재풀이 5문제
- [ ] 공고 확인
- [ ] 면접 소재 1개 추가
- [ ] 자소서 기반 예상 꼬리질문 3개 추가
- [ ] 경제·사회 이슈 2개 정리
- [ ] 다음 주 NotebookLM 재출제 목록 확정

- SQL: Structured Query Language, 구조화 질의어
