# 6. 하루 루틴

| 블록 | 내용 |
|---|---|
| 1블록 | NotebookLM 생성 문제 풀이 |
| 2블록 | 틀린 개념만 위키/정처기/기출 해설로 발췌 보강 |
| 3블록 | 5~7문장 서술형 답안 작성 |

## 7. 주간 점검표

매주 일요일 체크.

- [ ] NotebookLM 과목별 생성 문제 풀이 수 기록
- [ ] 한은 기출은 9월 전까지 직접 풀이하지 않고 스타일 참고 소스 상태 유지
- [ ] 서술형 답안 5문항 이상 작성
- [ ] 전공논술 1편 이상 작성
- [ ] 오답노트 업데이트
- [ ] NCS 2세트 이상
- [ ] SQL/코딩 유지
- [ ] 공고 확인
- [ ] 면접 소재 1개 추가
- [ ] 자소서 기반 예상 꼬리질문 3개 추가
- [ ] 경제·사회 이슈 2개 정리
- [ ] 다음 주 NotebookLM 재출제 목록 확정

## 약어 풀이

- NCS: National Competency Standards, 국가직무능력표준
- SQL: Structured Query Language, 구조화 질의어
