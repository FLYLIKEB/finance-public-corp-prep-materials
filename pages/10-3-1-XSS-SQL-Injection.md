# 10-3-1. XSS-SQL-Injection

> 학습 목적: XSS와 SQL Injection의 공격 위치를 구분한다.
> 관련 기출: [05-12-보안-기출-모음](05-12-보안-기출-모음.md)
> 연결 핵심정리: [04-4-네트워크-프로토콜-보안](04-4-네트워크-프로토콜-보안.md)

## 핵심 개념

- XSS는 악성 스크립트를 브라우저에서 실행하게 한다.
- SQL Injection은 입력값에 SQL 구문을 삽입해 DB를 조작한다.
- 입력 검증, 출력 인코딩, 파라미터 바인딩이 대응책이다.

## 쉽게 이해하기

- XSS는 게시판 글에 악성 스크립트를 심어 다른 사용자의 브라우저에서 실행시키는 공격이다.
- SQL Injection은 로그인 입력칸 등에 SQL 조각을 넣어 DB 명령을 바꿔 버리는 공격이다.
- XSS는 사용자 브라우저 쪽, SQL Injection은 데이터베이스 질의 쪽을 노린다고 구분하면 쉽다.

## 빈출 포인트

- 정의와 특징을 구분하는 객관식 문항
- 비슷한 개념 간 차이 비교
- 실제 기출 키워드와 연결한 빠른 복습

- 계산형 주제는 중간 과정을 생략하지 않는다.
