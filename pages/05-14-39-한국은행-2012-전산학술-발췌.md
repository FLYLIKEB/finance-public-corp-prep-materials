## 2012 전산학술 발췌

관계대수·SQL, 주소 지정 방식, MVC/스마트워크, IPv4/IPv6, 다중 스택 구현이 함께 나온다.

### I. 데이터베이스와 개념 문제

#### 1. A대학교 수강 데이터베이스

다음 스키마가 주어진다.

- 학과(학과번호, 학과명, 대표전화)
- 학생(학번, 학과번호, 성명, 학년, 주소)
- 과목(과목번호, 과목명, 학과번호, 구분)
- 수강(등록학기, 학번, 과목번호, 성적)

문항은 다음과 같다.

- `등록학기='201101'`, `과목번호='D101'` 조건의 **관계대수식** 작성
- 전산학과 학생 중 `201101` 학기에 **3과목 이상** 수강한 학생의 학번과 평균 성적을 구하는 SQL
- 과목 테이블 생성 SQL 작성
  - 문자 길이 제약
  - `과목명 NOT NULL`
  - `구분`은 `전공필수/전공선택/교양` 중 하나
  - 기본값 `전공필수`
  - 학과번호 갱신/삭제 시 참조무결성 동작 지정

#### 2. 개념 서술

간략 서술형으로 다음이 나온다.

- `MVC(Model-View-Control)` 패턴의 개념과 역할
- `Smart Work`의 개념과 유형
- `Augmented Reality`의 의미

### II. 컴퓨터구조와 네트워크

#### 1. 주소 지정 방식(Addressing Mode)

레지스터 상태(`PC=200`, `R1=400`, `XR=100`)와 메모리 상태가 주어진 뒤, 2워드 명령을 실행할 때 다음 주소 모드별로

- 유효 주소(Effective Address)
- 누산기 AC 값

을 채우게 한다.

- Direct
- Immediate
- Indirect
- Relative
- Indexed
- Register
- Register indirect
- Autoincrement
- Autodecrement

#### 2. IPv4 헤더와 IPv6

IPv4 헤더 구조를 보고 다음을 묻는다.

- `TTL`의 역할
- 어떤 헤더 항목의 한계 때문에 `IPv6`가 등장했는지, 그리고 IPv6에서의 개선 방식
- 계층별 헤더 길이와 목적지 네트워크 최대 패킷 크기가 주어졌을 때 **목적지 네트워크 접속 계층으로 전달되는 총 비트 수** 계산

### III. 자료구조

#### 1. 2개 스택을 1차원 배열에 구현

한 개의 배열로 `0번 스택`과 `1번 스택`을 함께 운영하는 `DoubleStack` Java 코드에서

- `push(int index, int item)`
- `pop(int index)`

메소드를 완성하는 문제다.

#### 2. 다중 스택 상태 추적

**2012 전산학술 — 다중 스택 초기상태 그림**

하나의 1차원 배열에 **세 개의 스택**을 운영할 때,

- `push(0,1)`
- `push(1,1)`
- `push(0,2)`
- `push(0,3)`
- `push(2,1)`
- `pop(0)`
- `push(2,2)`
- `push(1,2)`

연산 후의 **스택 상태 변화**를 채우는 문제다. 또한 스택이 가득 찼을 때 **오른쪽/왼쪽으로 한 칸씩 밀어 빈 공간을 만드는 규칙**도 함께 제시된다.
