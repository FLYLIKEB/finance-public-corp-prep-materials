## 보강 기준

- 프로세스, 스레드, 스케줄링, 메모리, 교착상태 문항을 발견하면 추가한다.
- 문항 원문은 기관별 페이지에 보존하고, 이 페이지에는 색인만 둔다.

## 약어 풀이

- CPU: Central Processing Unit, 중앙처리장치
- DMA: Direct Memory Access, 직접 메모리 접근
- FCFS: First-Come, First-Served, 선입선처리
- HRN: Highest Response-ratio Next, 최고 응답률 우선
- LRU: Least Recently Used, 최근 최소 사용
- RAID: Redundant Array of Independent Disks, 독립 디스크 중복 배열
- RAM: Random Access Memory, 임의 접근 메모리
- ROM: Read Only Memory, 읽기 전용 메모리
- RR: Round Robin, 라운드 로빈
- SJF: Shortest Job First, 최단 작업 우선
- SQL: Structured Query Language, 구조화 질의어
- TLB: Translation Lookaside Buffer, 주소 변환 캐시
