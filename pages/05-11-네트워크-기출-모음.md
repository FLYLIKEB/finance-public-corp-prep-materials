## 보강 기준

- OSI, TCP/IP, TCP/UDP, DNS, HTTP, TLS, 라우팅 문항을 발견하면 추가한다.
- 문항 원문은 기관별 페이지에 보존하고, 이 페이지에는 색인만 둔다.

## 약어 풀이

- 3-Way: 3-Way Handshake, TCP 연결 수립을 위한 3단계 절차
- DNS: Domain Name System, 도메인 이름 시스템
- HTTP: HyperText Transfer Protocol, 하이퍼텍스트 전송 프로토콜
- HTTPS: HyperText Transfer Protocol Secure, 보안 HTTP
- IP: Internet Protocol, 인터넷 프로토콜
- NIC: Network Interface Card, 네트워크 인터페이스 카드
- OSI: Open Systems Interconnection, 개방형 시스템 상호연결
- SSL: Secure Sockets Layer, 보안 소켓 계층
- TCP: Transmission Control Protocol, 전송 제어 프로토콜
- TLS: Transport Layer Security, 전송 계층 보안
- UDP: User Datagram Protocol, 사용자 데이터그램 프로토콜
- VPN: Virtual Private Network, 가상 사설망
