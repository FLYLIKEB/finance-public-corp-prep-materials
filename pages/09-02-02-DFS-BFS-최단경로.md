# 09-02-02. DFS-BFS-최단경로

> 학습 목적: 그래프 탐색과 최단경로의 기본 선택 기준을 정리한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-5-자료구조-알고리즘-DB-금융IT](04-05-자료구조-알고리즘-DB-금융IT.md)

## 핵심 개념

- DFS는 깊이 우선 탐색이다. 한 경로를 끝까지 따라가며 상태를 재귀(또는 스택)로 관리한다.
- BFS는 너비 우선 탐색이며 무가중치 그래프에서의 최단거리(간선 수 기준)와 연결된다. 큐를 사용해 레벨 단위로 탐색한다.
- 가중치 최단경로는 다익스트라(Dijkstra), 벨만-포드(Bellman-Ford), 플로이드-워샬(Floyd-Warshall) 등 상황에 따라 적합한 알고리즘을 선택한다.

### 복습 포인트(간단 요약)

- 탐색 목적이 "모든 정점 방문"이라면 DFS/BFS 둘 다 가능. 하지만 탐색 순서 요구(예: 깊이 우선 순서, 경로 존재 여부, 백트래킹 필요)에 따라 DFS/BFS를 선택한다.
- 최단경로 문제에서는 그래프의 간선 가중치 여부(무가중/음수 포함 여부), 단일 시작점 vs 모든 쌍 등 조건을 먼저 확인한다.

### 시험 포인트(정답을 빠르게 고르는 기준)

- 문제에 "간선의 가중치가 같다(또는 무가중)"면 최단거리는 BFS.
- 간선 가중치가 비음수(>= 0)이고 단일 출발점이면 Dijkstra.
- 음수 간선이 있고 음수 사이클 탐지도 필요하면 Bellman-Ford.
- 모든 쌍 최단경로가 필요하면 정점 수가 작을 때 Floyd-Warshall.
- 그래프가 희소(sparse)하면 인접 리스트 + 우선순위 큐(다익스트라) 사용이 효율적.

## 서술형 확장 개념

- 그래프 표현 선택
  - 인접 행렬: 간선 존재 확인 O(1), 공간 O(V^2). 정점 수 V가 작고 간선이 많을 때(밀집 그래프) 적합.
  - 인접 리스트: 공간 O(V + E). 희소 그래프(sparse)에 적합하며 대부분의 실무/대회 문제에서는 기본 선택.

- Dijkstra
  - 음수 간선이 없을 때 단일 시작점 최단경로에 적합.
  - 우선순위 큐(힙)를 쓰면 일반적으로 O((V + E) log V) 또는 간선 수에 따라 O(E log V)로 설명.
  - 구현 시 방문 배열만으로 최적화하면 잘못된 결과를 만들 수 있으니 현재 꺼낸 거리와 저장된 거를 비교해 무시하는 패턴을 사용.

- Bellman-Ford
  - 음수 간선을 허용하고 음수 사이클을 탐지 가능.
  - 시간복잡도 O(V * E)로 대체로 느림. 음수 간선 처리가 핵심인 문제에서 사용.

- Floyd-Warshall
  - 모든 쌍 최단경로를 O(V^3)로 계산. 정점 수가 작을 때(예: V <= 400 정도, 문제 조건에 따라 변동) 사용.

- MST(최소 신장 트리)
  - Kruskal: 간선을 정렬 후 Union-Find로 사이클을 방지하며 선택. 간선 수 정렬 비용이 핵심.
  - Prim: 한 정점에서 시작해 인접한 최소 간선을 반복 선택. 우선순위 큐를 쓰면 희소 그래프에서 효율적.

- 위상 정렬
  - DAG에서 선후관계를 만족하는 순서 생성. 진입 차수(indegree)가 0인 정점을 큐에 넣고 제거해 가며 처리.
  - 처리한 정점 수가 V보다 작으면 사이클 존재.

## 알고리즘 선택 체크리스트

- 주어진 그래프에 대해 다음을 차례로 확인하라:
  - 간선에 가중치가 있는가? 없다면 BFS로 최단거리 가능.
  - 가중치에 음수가 포함되는가? 포함된다면 Bellman-Ford 가능성 검토.
  - 단일 출발점 vs 모든 쌍 문제인가? 단일이면 Dijkstra/Bellman-Ford, 모든 쌍이면 Floyd-Warshall.
  - 그래프가 희소인가 밀집인가? 희소면 인접 리스트 + 힙을 고려.
  - 사이클을 판별해야 하는가(예: 위상 정렬)? 필요하면 위상 정렬 또는 DFS 사이클 검사 사용.

- 시험 응용 예시:
  - "두 정점 사이 최단 거리(간선 수 기준)" → BFS로 해결.
  - "가중치가 있고 음수 없음, 시작점 고정" → Dijkstra.
  - "음수 간선 존재, 음수 사이클 여부 검사" → Bellman-Ford.
  - "모든 쌍 거리 테이블이 필요" → Floyd-Warshall.

## 구현 팁 & 실무 연결

- DFS 구현 시
  - 재귀 깊이 초과 주의(정점 수가 큰 경우). 반복문(스택)으로 대체하거나 재귀 한도를 늘려야 할 수 있음.
  - 방문 체크(visited)를 적절한 시점에 하여 중복 방문을 막아야 함(특히 무향 그래프에서 중요).

- BFS 구현 시
  - 최단거리 구할 때는 거리 배열(dist)을 사용하고, 큐에서 꺼내는 순간이 최단거리 확정 시점(무가중 기준).
  - 목적지 조기 종료(early exit)가 가능하면 시간 절약.

- Dijkstra 구현 시
  - 우선순위 큐에 (거리, 정점) 튜플을 넣고, 꺼낸 거리와 현재 저장된 거리 비교로 obsolete 상태를 무시하는 패턴을 사용한다.
  - 인접 리스트를 사용할 때 메모리와 시간 효율성을 확보할 수 있다.

- 실무 적용 예시
  - 네트워크 라우팅: 가중치(지연시간, 비용)에 따른 최단경로 → Dijkstra 계열.
  - 작업 스케줄링/종속성 해결: 위상 정렬.
  - 거리 기반 추천, 지도 경로 탐색(도로 가중치) 등: 상황에 따라 Dijkstra, A*(휴리스틱 포함, 본 문서 범위 밖).
  - 그래프 유효성 검사(순환 의존성): 위상 정렬 또는 DFS 사이클 검사.

## 짧은 코드 예시(참고)

- BFS(무가중 최단거리, Python 스타일 의사 코드)

```
from collections import deque

def bfs(start):
    dist = [-1] * (N+1)
    q = deque([start])
    dist[start] = 0
    while q:
        v = q.popleft()
        for nx in adj[v]:
            if dist[nx] == -1:
                dist[nx] = dist[v] + 1
                q.append(nx)
    return dist
```

- Dijkstra(단일 출발점, 음수 없음)

```
import heapq

def dijkstra(start):
    INF = 10**18
    dist = [INF] * (N+1)
    dist[start] = 0
    hq = [(0, start)]
    while hq:
        d, v = heapq.heappop(hq)
        if d != dist[v]:
            continue
        for w, cost in adj[v]:
            nd = d + cost
            if nd < dist[w]:
                dist[w] = nd
                heapq.heappush(hq, (nd, w))
    return dist
```

> 주: 위 코드는 학습용 의사 코드다. 실제 문제에서 인덱스 범위(N), 그래프 입력 방식(adj 생성), 메모리 제약을 확인해야 한다.
