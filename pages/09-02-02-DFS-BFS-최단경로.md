# 09-02-02. DFS-BFS-최단경로

> 학습 목적: 그래프 탐색과 최단경로의 기본 선택 기준을 정리한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-5-자료구조-알고리즘-DB-금융IT](04-05-자료구조-알고리즘-DB-금융IT.md)

## 핵심 개념

- DFS는 깊이 우선 탐색이다.
- BFS는 너비 우선 탐색이며 무가중치 최단거리와 연결된다.
- 가중치 최단경로는 다익스트라 등을 사용한다.


### 서술형 확장 개념

- 그래프 표현은 입력 크기에 맞춰 고른다. 인접 행렬은 간선 존재 확인이 O(1)이지만 공간이 O(V²)이고, 인접 리스트는 공간이 O(V+E)라 sparse graph에 적합하다.
- Dijkstra는 간선 가중치가 음수가 없을 때 하나의 시작점에서 최단경로를 구한다. 우선순위 큐를 쓰면 보통 O((V+E)logV)로 설명한다.
- Bellman-Ford는 음수 간선을 허용하고 음수 사이클을 탐지할 수 있지만 O(VE)로 느리다. Floyd-Warshall은 모든 쌍 최단경로를 O(V³)에 구하므로 정점 수가 작을 때 적합하다.
- MST는 모든 정점을 최소 비용으로 연결하는 트리다. Kruskal은 간선을 비용순으로 정렬하고 Union-Find로 사이클을 막으며, Prim은 하나의 정점 집합을 확장한다.
- 위상정렬은 DAG에서 선후관계를 만족하는 순서를 구한다. 진입차수 0인 정점을 큐에 넣어 처리하며, 처리한 정점 수가 V보다 작으면 사이클이 있다.

| 문제 조건 | 대표 알고리즘 |
| --- | --- |
| 무가중치 최단거리 | BFS |
| 음수 없는 단일 시작점 최단경로 | Dijkstra |
| 음수 간선/음수 사이클 탐지 | Bellman-Ford |
| 모든 쌍 최단경로 | Floyd-Warshall |
| 최소 연결 비용 | Kruskal, Prim |

## 쉽게 이해하기

- DFS는 한 길을 끝까지 가 보고 막히면 돌아오는 탐색이다. 미로에서 한 방향으로 깊게 들어가는 방식이다.
