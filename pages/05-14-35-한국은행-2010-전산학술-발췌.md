## 2010 전산학술 발췌

운영체제, 데이터베이스, 네트워크 QoS, 허프만 압축, 소프트웨어 규모 산정이 한 문서에 묶인 발췌본이다.

### I. 객관·선택형 중심 발췌

#### 1. 프로세스 생성 수 계산

아래 `fork()` 코드가 실행될 때 **시작 프로세스를 포함해 총 몇 개의 프로세스가 생성되는지** 묻는 문제.

```c
int main()
{
    if (fork() > 0)
        fork();
}
```

선택지는 `A. 1 / B. 2 / C. 3 / D. 4 / E. ∞` 형식이다.

### II. 단답·서술형 발췌

#### 1. 은행 데이터베이스 SQL

다음 테이블을 바탕으로 문제를 푼다.

- 고객(성명, 주소, 나이)
- 지점(지점명, 주소, 자산)
- 계좌(계좌번호, 지점명, 잔고, 구분)
- 예금(성명, 계좌번호)

요구사항은 다음과 같다.

- `계좌` 테이블 생성 SQL 작성
  - 계좌번호 문자 10자리
  - 지점명 문자 20자리
  - 잔고는 정수, `0 이상`
  - 구분 기본값은 `예금`
  - 지점명 변경 시 자동 반영
- 성이 `김`이고 20대이며 **최소 2개 계좌**를 가진 고객의
  - 성명
  - 잔고 평균
  을 구하는 SQL 작성

#### 2. 인터넷 QoS 스케줄링

라우터에 `3개 입력 플로우`와 `1개 출력 플로우`가 있고, 패킷 1~8의 크기와 플로우 번호가 주어졌을 때 다음 스케줄링 방식의 **전송 순서**를 쓰는 문제다.

- RR(Round Robin)
- FQ(Fair Queueing)
- WFQ(Weighted Fair Queueing)

단, `WFQ`에서는 **2번 입력 플로우의 weight만 2**이고 나머지는 1이다.

#### 3. 클라우드 컴퓨팅 vs 유틸리티 컴퓨팅

두 개념의 공통점과 차이점을 비교 서술하는 문제다.
