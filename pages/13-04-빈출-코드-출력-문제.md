## 핵심 개념

- 반복문 변수 변화를 표로 적는다.
- 조건문 분기마다 출력 여부를 표시한다.
- 재귀는 호출 스택과 반환값을 함께 추적한다.


### 코드 추적 예제

```c
int x = 1;
void f(int a) { a++; x += a; }
int main() { int x = 3; f(x); printf("%d", x); }
```

`f(x)`의 인자 `a`는 값 복사이고, 함수 안의 `x`는 전역 변수다. 따라서 지역 변수 `x=3`은 바뀌지 않아 출력은 3이다. 전역/지역 scope와 pass-by-value를 분리해 추적해야 한다.

```python
def g(n):
    if n == 0: return 1
    print(n)
    return n * g(n-1)
print(g(3))
```

출력은 호출이 내려갈 때 `3, 2, 1`이 먼저 나오고, 반환이 올라오며 `6`이 마지막에 출력된다. 재귀 출력 문제는 “호출 전 출력인지, 반환 후 출력인지”가 핵심이다.

## 쉽게 이해하기

- 코드 출력 문제는 컴퓨터가 한 줄씩 실행하는 과정을 사람이 따라가는 문제다.
- 변수 값이 바뀔 때마다 표에 기록하면 반복문과 조건문 실수를 줄일 수 있다.
- 재귀나 중첩 반복문은 머리로만 풀지 말고 호출 순서와 출력 시점을 따로 표시한다.
