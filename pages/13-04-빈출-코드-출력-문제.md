# 13-04. 빈출 코드 출력 문제

> 학습 목적: 코드 실행 흐름을 손으로 추적하는 습관을 만든다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-2-프로그래밍-SQL-분산-클라우드](04-02-프로그래밍-SQL-분산-클라우드.md)

## 핵심 개념

- 반복문 변수 변화를 표로 적는다.
- 조건문 분기마다 출력 여부를 표시한다.
- 재귀는 호출 스택과 반환값을 함께 추적한다.

## 쉽게 이해하기

- 코드 출력 문제는 컴퓨터가 한 줄씩 실행하는 과정을 사람이 따라가는 문제다.
- 변수 값이 바뀔 때마다 표에 기록하면 반복문과 조건문 실수를 줄일 수 있다.
- 재귀나 중첩 반복문은 머리로만 풀지 말고 호출 순서와 출력 시점을 따로 표시한다.
