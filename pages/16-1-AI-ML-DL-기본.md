# 16-1. AI·ML·DL 기본

## 핵심 개념

- AI는 지능적 행동을 수행하는 시스템 전체를 뜻하며 규칙 기반 추론, 탐색, 기계학습까지 모두 포함한다.
- ML은 데이터로부터 입력과 출력의 관계를 학습해 예측 함수를 만드는 방법론이다.
- DL은 다층 신경망으로 표현을 자동 학습하는 ML의 하위 분야다.
- 면접에서는 “AI ⊃ ML ⊃ DL” 구조를 먼저 말한 뒤 금융 예시를 붙이면 답이 짧고 명확해진다.

## 학습 유형

| 유형 | 입력 데이터 | 대표 과업 | 금융 예시 |
| --- | --- | --- | --- |
| 지도학습 | 라벨 있음 | 분류, 회귀 | 신용평가, 민원 분류 |
| 비지도학습 | 라벨 없음 | 군집화, 차원 축소, 이상 탐지 | 고객 세분화, 거래 패턴 탐색 |
| 강화학습 | 상태·행동·보상 | 정책 학습 | 트레이딩 연구, 자원 배분 시뮬레이션 |

## 자주 같이 나오는 구분

- **회귀**: 금액, 시간, 확률 점수처럼 연속값을 예측한다.
- **분류**: 정상/사기, 승인/거절처럼 범주를 예측한다.
- **특성(feature)**: 모델 입력으로 쓰는 변수다.
- **라벨(label)**: 정답 값이다.
- **파라미터(parameter)**: 모델이 학습으로 조정하는 내부 값이다.

## 과적합과 과소적합

- 과적합은 훈련 데이터에는 잘 맞지만 새 데이터 성능이 떨어지는 상태다.
- 과소적합은 모델이 너무 단순해 훈련 데이터의 기본 패턴도 설명하지 못하는 상태다.
- Bias-variance trade-off는 모델이 단순할수록 편향이 커지고, 복잡할수록 분산이 커질 수 있다는 균형 문제다.

## 면접 답안 포인트

- AI는 넓은 개념, ML은 데이터 학습, DL은 신경망 기반 학습이라고 층위를 나눠 설명한다.
- 금융권에서는 성능만이 아니라 설명가능성, 승인 절차, 개인정보 보호까지 같이 봐야 한다고 덧붙이면 답안 밀도가 올라간다.
- 강화학습은 출제 빈도는 낮지만 “정답 라벨 대신 보상으로 학습한다” 한 문장은 기억해 두는 편이 좋다.
