# 05-15. 코스콤 IT 기출

## 코스콤 IT직군 빈출 영역

코스콤은 자본시장 IT 인프라를 운영하므로 시스템 아키텍처, 클라우드, 보안, 네트워크, 데이터베이스 성능과 관련된 문제가 중요합니다. 거래 시스템의 저지연·고가용성 특성을 이해하면 필기와 면접 모두에서 유리합니다.

## 대표 유형

| 영역 | 출제 포인트 | 대비 방법 |
|---|---|---|
| 시스템 아키텍처 | 고가용성, 이중화, 로드밸런싱 | 장애 지점과 복구 전략 설명 |
| 클라우드 | 컨테이너, 오토스케일링, 가상화 | 온프레미스와 비교 |
| 보안 | 인증·인가, 암호화, 웹 공격, 로그 감사 | 금융투자 데이터 보호와 연결 |
| DB/성능 | 인덱스, 캐시, 락, 트랜잭션 | 주문·체결 지연 감소 관점 |
| 네트워크 | 지연시간, TCP, 라우팅, TLS | 저지연 거래 인프라와 연결 |

## 예시 문제

1. 액티브-액티브와 액티브-스탠바이 이중화 구조의 장단점을 비교하시오.
2. 캐시를 적용할 때 발생할 수 있는 데이터 일관성 문제와 해결책을 설명하시오.
3. 컨테이너와 가상머신의 차이를 설명하고 금융권 운영 환경에서 고려할 점을 쓰시오.
4. XSS와 SQL Injection의 차이와 방어 방법을 설명하시오.

## 기관별 출제 경향 비교

| 기관 | 핵심 키워드 | 답안 방향 |
|---|---|---|
| 한국은행 | 금융 안정, 지급결제, CBDC | 정책·금융 인프라 관점 |
| 코스콤 | 자본시장 IT, 저지연, 보안 | 시스템 운영·성능 관점 |
| 금융결제원 | 공동망, 인증, 결제 안정 | 거래 정합성·보안 관점 |

## 학습 팁

코스콤 문제는 “빠른 시스템”보다 “빠르면서 안전하고 중단 없는 시스템”으로 답해야 합니다. 성능 개선 경험은 항상 장애 대응, 모니터링, 보안 통제와 함께 정리합니다.

## 약어 풀이

- CBDC: Central Bank Digital Currency, 중앙은행 디지털화폐
- DB: Database, 데이터베이스
- IT: Information Technology, 정보기술
- SQL: Structured Query Language, 구조화 질의어
- TCP: Transmission Control Protocol, 전송 제어 프로토콜
- TLS: Transport Layer Security, 전송 계층 보안
