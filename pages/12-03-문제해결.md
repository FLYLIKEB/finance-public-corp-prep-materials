## 핵심 개념

- 조건은 표나 기호로 변환한다.
- 확정 조건과 가능 조건을 분리한다.
- 반례를 통해 선지를 제거한다.

설명 보강

- 조건을 표나 기호로 바꾸면 머릿속 불명확함을 제거하고 논리적 누락을 줄인다. 예: "A는 B이면 C"를 A ∧ B → C 또는 조건표로 기록.
- 확정 조건(항상 참인 조건)과 가능 조건(경우에 따라 참인 조건)을 따로 표기하면 추론 단계에서 잘못된 전제를 사용하지 않는다.
- 반례(contradiction) 탐색은 선택지를 제거하는 빠른 방법이다. 어떤 선지가 참일 때 모순이 발생하면 그 선지는 틀렸다.

## 쉽게 이해하기

- 문제해결은 여러 조건을 정리해 가능한 경우를 좁히는 영역이다.
- 머릿속으로만 풀면 헷갈리므로 표, 기호, 순서도로 바꾸는 것이 좋다.
- 확정 조건과 아직 가능한 조건을 분리하면 추론 실수가 줄어든다.

추가 팁

- 조건 간의 우선순위(예: 필수 vs 선택)를 명확히 하라. 시험에서는 필수 조건을 놓쳐 오답을 선택하는 경우가 빈번하다.
- 서로 배타적인 조건(상호배타)인지, 동시에 가능해 보이는 조건인지 표에 표시하라.

## 문제풀이 절차(권장)

1. 문제 문장을 한 번 읽고 핵심 조건을 밑줄 친다.
2. 조건들을 한 줄짜리 문장으로 재서술해 명확하게 분리한다.
3. 확정 조건(항상 적용)과 가능 조건(케이스별 적용)을 표나 기호로 구분해 정리한다.
4. 가능한 경우의 수를 표나 표 형태로 만들고, 조건을 하나씩 적용해 제거하는 방식으로 좁힌다.
5. 반례를 찾아 남은 후보를 검증한다. 반례가 있으면 그 후보는 배제한다.
6. 최종 선택지를 문제 요구(유일성, 최대/최소 등)에 따라 확인하고 답안을 작성한다.

## 체크리스트

- [ ] 문제의 모든 조건을 모두 추출했는가?
- [ ] 각 조건을 표나 기호로 재표현했는가?
- [ ] 확정/가능 조건을 구분했는가?
- [ ] 상호배타(또는 동시가능) 표기를 했는가?
- [ ] 반례로 후보를 제거했는가?
- [ ] 남은 해를 문제 요구사항으로 최종 검증했는가?

## 시험 포인트

- 필요한/충분 조건 구분: 어떤 조건이 반드시 필요한지(필수), 어떤 조건이 성립하면 결과가 따른다고 볼 수 있는지(충분)를 시험문항이 자주 묻는다.
- 중복 조건 제거: 같은 의미의 조건이 다른 말로 주어질 때 이를 통합하면 풀이 시간이 단축된다.
- 상호배타(Exclusive) 함정: 시험에서는 ‘또는’이 배타적인지 포함적인지 상황에 따라 달라진다. 문제 문장으로부터 정확히 해석해야 한다.
- 반례 제시 능력: 선택지를 배제할 때 하나의 반례만으로도 오답을 확정할 수 있다. 반례 찾기는 빠른 시간 내에 결론을 내리는 데 유리하다.
- 경우의 수 관리: 경우의 수가 많은 문제는 표로 정리하거나 트리로 분기해 하나씩 제거하는 것이 안전하다.

## 실무 연결

- 요구사항/사양서 해석: 여러 조건을 정리해 충돌이나 누락을 찾는 과정은 요구사항 분석에서 그대로 사용된다.
- 버그 재현 및 원인 분석: 조건을 분리·정리하면 어떤 입력 조합에서 문제가 재현되는지 빠르게 찾을 수 있다.
- 테스트 케이스 설계: 확정/가능 조건을 기준으로 경계값과 예외 케이스를 추출해 테스트 케이스를 생성한다.
- 데이터 필터링/쿼리 작성: SQL 등에서 조건을 논리적으로 정리해 WHERE 절을 설계하면 오동작을 줄일 수 있다.

구체적 예시(실무)

- 규격서에 명시된 제약 조건들이 상호 충돌하는지 표로 만들어 검토한다. 충돌이 있으면 우선순위를 명확히 해 의사결정 문서를 작성한다.
- 제품 기능의 동작 조건들을 정리해 테스트 시나리오(정상/예외)를 자동화한다.

## 예제: 간단한 조건 추론

다음은 연습용 간단한 논리 문제와 풀이 흐름이다.

문제

"사람 3명(A, B, C)이 있고, 각각 하나의 색(빨강, 파랑, 초록)을 입었다. 조건: (1) A는 파랑이 아니다. (2) B는 빨강이거나 초록이다. (3) C가 초록이면 B는 파랑이다."

풀이 전략

1. 가능한 색 조합을 표로 만든다(중복 불가 가정).
2. 조건(1)-(3)을 차례로 적용해 불가능한 조합을 제거한다.

간단한 풀이(코드펜스 형식으로 가독성 유지)

```
가능 색: {빨강, 파랑, 초록}
모든 순열(중복 없음) 고려: 3! = 6가지
A,B,C 순서로 목록: 
1) R,B,G  2) R,G,B  3) B,R,G  4) B,G,R  5) G,R,B  6) G,B,R
조건 (1): A != 파랑 -> 제거: 3,4
남은: 1,2,5,6
조건 (2): B == 빨강 OR 초록 -> 남기려면 B가 빨강 또는 초록이어야 함
  1) R,B,G (B= B? 파랑) => B는 파랑이므로 조건2 위배 -> 제거
  2) R,G,B (B=G) -> 허용
  5) G,R,B (B=R) -> 허용
  6) G,B,R (B=B) -> B가 파랑 => 제거
남은: 2,5
조건 (3): 만약 C==초록이면 B==파랑
  2) R,G,B -> C=B(파랑) 이므로 전건 거짓(초록 아님) => 조건3 영향 없음
  5) G,R,B -> C=B(파랑) 역시 영향 없음
결과: 남은 조합 2)와 5)
문제 요구(유일성 등)에 따라 추가 조건이 없으면 해는 2개
```

해설

- 이 예제는 조건을 표(또는 목록)로 정리하고 하나씩 적용해 제거하는 전형적인 풀이 과정을 보여준다.
- 시험에서는 ‘유일한 정답’ 여부를 묻는 경우가 많으니 문제 요구사항을 반드시 확인하라.
