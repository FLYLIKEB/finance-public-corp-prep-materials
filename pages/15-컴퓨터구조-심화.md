# 15. 컴퓨터구조 심화

금융공기업 IT 필기에서 컴퓨터구조는 운영체제·네트워크와 함께 시스템 전반의 성능과 안정성을 설명하는 핵심 과목입니다. 특히 금융결제원·산업은행 전산 직무에서는 CPU 실행 구조, 캐시, 명령어, 입출력 병목을 묻는 문제가 반복됩니다.

## 기관별 기출 연계

| 기관 | 자주 연결되는 주제 | 대비 포인트 |
|---|---|---|
| 금융결제원 | 인터럽트, DMA, 캐시 일관성, 장애 대응 | 결제망 처리 지연과 I/O 병목을 시스템 관점으로 설명 |
| 산업은행 | CPU 파이프라인, 메모리 계층, RISC/CISC | 업무 시스템 성능 개선과 인프라 이해로 연결 |
| 코스콤 | 저지연 처리, 캐시, 분기 예측 | 거래 시스템 성능과 하드웨어 구조의 관계 이해 |

## 학습 순서

CPU 설계 → 캐시와 메모리 계층 → 명령어 세트 → 입출력 시스템 순서로 학습하면 “연산이 어떻게 실행되고, 어디서 병목이 생기며, 운영체제가 이를 어떻게 제어하는지”를 한 흐름으로 이해할 수 있습니다.
