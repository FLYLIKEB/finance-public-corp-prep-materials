## 10. 자료구조: 해시

자료구조와 관련하여 다음 물음에 답하시오.

### 가.

해시 함수에서 충돌이 발생하는 이유와 해결 방법인 **개방 주소법(Open Addressing)**과 **체이닝(Chaining)**에 대해 서술하시오.

### 나.

아래 좌측은 해시 테이블에 데이터를 삽입하기 위한 프로그램이며, 우측의 해시 테이블은 `insertHash` 함수를 사용하여 18, 37, 25를 삽입한 결과이다. 22, 35, 50, 63을 순차적으로 `insertHash` 함수를 사용하여 삽입했을 때의 결과를 우측의 해시 테이블에 작성하고, 이 방법의 문제점에 대해 서술하시오.

```c
#define SIZE 13

int hashTable[SIZE] = {};

int Hash(int key){
    return key % SIZE;
}

void insertHash(int key){
    int probe = Hash(key);
    while(hashTable[probe] != NULL){
        probe = (probe + 1) % SIZE;
    }
    hashTable[probe] = key;
}
```
