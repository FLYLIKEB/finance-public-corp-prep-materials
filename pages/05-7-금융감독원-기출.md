## 금융감독원

### 187. 중간자 공격 문제
**답(AI답변):** 중간자 공격은 통신 당사자 사이에 공격자가 개입해 도청·변조하는 공격이다.
### 188. 캐쉬 쓰기정책 문제
**답(AI답변):** Write-through는 캐시와 메모리에 동시에 기록해 일관성이 좋고, Write-back은 캐시에 먼저 쓰고 나중에 반영해 성능이 좋다.
### 189. 선택암호문 문제
**답(AI답변):** 선택암호문 공격(CCA)은 공격자가 선택한 암호문에 대한 복호 결과를 이용해 비밀키/평문 정보를 추론하는 공격이다.
### 190. 무결성 문제
**답(AI답변):** 무결성은 데이터가 허가 없이 변경·훼손되지 않고 정확성과 완전성을 유지하는 보안 속성이다.
### 191. 정렬 시간복잡도 문제
**답(AI답변):** 문제의 선지/도표가 원문에 충분히 남아 있지 않아 단정형 정답은 제한적이다. 해당 주제의 핵심 개념과 대표 공식·특징을 기준으로 풀이해야 한다.
### 192. Risc/cisc 문제
**답(AI답변):** RISC는 단순·고정 길이 명령어와 레지스터 중심, CISC는 복잡·가변 길이 명령어와 메모리 중심 특징이 있다.
### 193. Rsa 문제
**답(AI답변):** RSA는 큰 수의 소인수분해 어려움에 기반한 공개키 암호 알고리즘이다.
### 194. 전자서명 문제
**답(AI답변):** 전자서명은 송신자가 개인키로 서명하고 수신자가 공개키로 검증해 인증, 무결성, 부인방지를 제공한다.
### 195. LRU 계산문제 문제
**답(AI답변):** LRU는 가장 오랫동안 사용되지 않은 페이지를 교체한다.
### 196. 하이브리드 클라우드에 대한 설명으로 옳지 않은 것은?
**답(AI답변):** 하이브리드 클라우드는 퍼블릭과 프라이빗 클라우드를 연계해 사용하는 방식이다.
### 197. 하둡 뜻
**답(AI답변):** Hadoop은 HDFS와 MapReduce 기반의 대용량 분산 저장·처리 프레임워크다.
### 198. 충돌직렬성 문제
**답(AI답변):** 충돌 직렬 가능성은 충돌 연산 순서를 보존하면서 어떤 직렬 스케줄과 동등한지 판단한다. 우선순위 그래프에 사이클이 없으면 충돌 직렬 가능하다.
### 199. 전위 중위 연산자 트리그리기 문제
**답(AI답변):** 전위 순회는 Root-Left-Right, 중위 순회는 Left-Root-Right 순서다. 두 순회를 이용해 이진트리를 복원할 수 있다.
### 200. AOE 유형 중 옳지 않은 것은?
**답(AI답변):** AOE 네트워크는 작업을 간선으로 표현하고 이벤트를 정점으로 표현해 프로젝트 일정/임계경로를 분석한다.
### 201. (약술) IPv4 vs IPv6 특징

  → IPv4는 32비트의 주소체계를 가진 데이터를 교환하기 위한 네트워크 계층의 프로토콜

  → IPv6는 IPv4가 가지고 있는 주소고갈, 보안성 등의 문제점을 해결하기 위해서 개발된 128비트 주소체계를
갖는 차세대 인터넷 프로토콜
**답(AI답변):** IPv4는 32비트 주소체계, IPv6는 128비트 주소체계다. IPv6는 주소 고갈 완화, 자동 설정, 확장 헤더, 보안성 개선 특징이 있다.
### 202. (약술) 가상화서버 도입함으로써 생기는 장점

  → 서버 가용성이 증가하고 운영비용이 절감된다. 또한 무분별한 서버확장과 복잡성을 제거한다
**답(AI답변):** 서버 통합으로 자원 활용률과 가용성이 증가하고, 운영비·관리비를 절감하며 확장성과 복구성이 좋아진다.
### 203. (약술) Daisy Chain 개념

  → 데이지 체인이란 연속적으로 연결되어 있는 하드웨어 장치들의 구성이다
**답(AI답변):** 데이지 체인은 장치들을 직렬로 연속 연결하는 구성 방식이다.
### 204. (약술) 지역성 개념

    → 지역성이란 기억장치 내의 특정 부분을 집중적으로 참조하는 특성이다. 시간 지역성은 최근에 사용되었던
기억장소들이 집중적으로 엑세스 되는 경향이고 공간지역성은 하나의 기억장소가 가까운 장래에도 참조될
가능성이 높음을 의미한다.
**답(AI답변):** 시간 지역성은 최근 참조한 데이터 재참조 가능성, 공간 지역성은 인접 주소 참조 가능성이 높은 특성이다.
### 205. 클라우드 시스템 분류 및 특징 약술
- IaaS(인프라형 서비스): 물리적 자원을 가상화하여 인프라를 제공함. 예: 서버, 스토리지, 네트워크 등.
- PaaS(플랫폼형    서비스):   개발자가   애플리케이션을      개발하고 배포할   수   있도록   플랫폼을   제공함.   예:
    애플리케이션 개발 환경, 데이터베이스 등.
- SaaS(소프트웨어형 서비스): 최종 사용자가 이용할 수 있는 소프트웨어 애플리케이션을 제공함. 예: 이메일,
    CRM, 협업 도구 등.
**답(AI답변):** IaaS는 인프라 제공, PaaS는 개발 플랫폼 제공, SaaS는 완성 소프트웨어 제공이다.
