# 14-5. 한국거래소 자기소개서 가이드

## 기관 이해

한국거래소는 유가증권·코스닥·파생상품 시장을 운영하고, 공정한 가격 형성과 시장 감시 기능을 수행합니다. 자기소개서에서는 거래 시스템의 안정성, 시장 공정성, 데이터 분석 역량을 함께 보여주는 것이 좋습니다.

## 거래소 시스템 특성

- 실시간 주문·체결 처리에서 저지연과 고가용성이 중요합니다.
- 시장 감시와 이상거래 탐지는 데이터 분석과 규칙 기반 탐지가 결합됩니다.
- 상장·공시·청산 등 시장 운영 전반의 정보 시스템이 연결됩니다.

## 데이터 분석 경험 어필

| 분석 역량 | 거래소 연결 포인트 |
|---|---|
| 이상치 탐지 | 불공정거래 징후 탐지, 로그 분석 |
| 대용량 처리 | 주문·체결 데이터 처리, 실시간 모니터링 |
| 시각화 | 시장 상황 대시보드, 리스크 지표 공유 |
| 모델 검증 | 오탐·미탐 균형, 설명 가능한 기준 수립 |

## 문항별 작성 전략

### 지원동기

“공정하고 투명한 자본시장 운영을 IT로 뒷받침하고 싶다”는 방향이 좋습니다. 개인 투자 경험을 중심에 두기보다 시장 인프라와 공공성을 강조합니다.

### 직무역량

실시간 처리, 성능 개선, 데이터 분석, 보안 경험을 거래소의 시장 운영·감시 시스템과 연결합니다. 성능 개선 경험은 체결 시스템 안정성으로, 데이터 분석 경험은 이상거래 탐지와 시장 투명성으로 확장합니다.

### 문제해결 경험

정답이 명확하지 않은 데이터를 기준화하거나, 여러 지표를 조합해 문제 원인을 찾은 경험이 좋습니다. 거래소 업무는 기술적 판단이 시장 신뢰와 연결된다는 점을 표현합니다.

## 한 문장 템플릿

> 저는 실시간 시스템과 데이터 분석 경험을 바탕으로, 한국거래소의 공정하고 투명한 시장 운영을 기술적으로 뒷받침하는 IT 인재가 되고 싶습니다.
