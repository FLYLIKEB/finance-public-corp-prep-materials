# 13-02. 구현

> 학습 목적: 기본 구현 문제의 입출력과 조건 처리를 안정화한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-2-프로그래밍-SQL-분산-클라우드](04-02-프로그래밍-SQL-분산-클라우드.md)

## 핵심 개념

- 입력 형식과 출력 형식을 먼저 고정한다.
- 조건 분기와 반복문 경계를 확인한다.
- 작은 예제로 상태 변화를 추적한다.

## 쉽게 이해하기

- 구현 문제는 어려운 이론보다 요구사항을 정확히 코드로 옮기는 능력을 본다.
- 입력, 처리, 출력 세 단계를 나눠 적으면 실수가 줄어든다.
- 복잡해 보이면 작은 예제를 손으로 먼저 실행해 보고 코드로 옮긴다.

## 빈출 포인트

- 정의와 특징을 구분하는 객관식 문항
- 비슷한 개념 간 차이 비교
- 실제 기출 키워드와 연결한 빠른 복습

- 예외와 반례가 있는 선지를 주의한다.
- 계산형 주제는 중간 과정을 생략하지 않는다.
