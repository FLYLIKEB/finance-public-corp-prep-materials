# 14. 컴퓨터구조 심화

금융공기업 IT 필기에서 컴퓨터구조는 운영체제·네트워크와 함께 시스템 전반의 성능과 안정성을 설명하는 핵심 과목입니다. 특히 금융결제원·산업은행 전산 직무에서는 CPU 실행 구조, 캐시, 명령어, 입출력 병목을 묻는 문제가 반복됩니다.

## 기관별 기출 연계

| 기관 | 자주 연결되는 주제 | 대비 포인트 |
|---|---|---|
| 금융결제원 | 인터럽트, DMA, 캐시 일관성, 장애 대응 | 결제망 처리 지연과 I/O 병목을 시스템 관점으로 설명 |
| 산업은행 | CPU 파이프라인, 메모리 계층, RISC/CISC | 업무 시스템 성능 개선과 인프라 이해로 연결 |
| 코스콤 | 저지연 처리, 캐시, 분기 예측 | 거래 시스템 성능과 하드웨어 구조의 관계 이해 |

각 기관 문제는 단순 정의보다 "왜 병목이 생기고 어떤 구조가 이를 줄이는가"를 묻는 형태가 많습니다. 따라서 개별 개념을 외우는 것보다 CPU → 메모리 → I/O로 이어지는 전체 흐름을 한 문장으로 설명하는 연습이 중요합니다.

## 학습 순서

CPU 설계 → 캐시와 메모리 계층 → 명령어 세트 → 입출력 시스템 순서로 학습하면 “연산이 어떻게 실행되고, 어디서 병목이 생기며, 운영체제가 이를 어떻게 제어하는지”를 한 흐름으로 이해할 수 있습니다.

추천 복습 흐름은 다음과 같습니다.

1. `CPU time = Instruction Count × CPI × Clock Cycle Time` 공식을 먼저 익힌다.
2. 파이프라인 5단계와 해저드(구조적·데이터·제어)를 연결한다.
3. 캐시 계층과 TLB가 평균 메모리 접근 시간을 어떻게 줄이는지 정리한다.
4. ISA, 주소 지정 방식, RISC/CISC 차이를 통해 소프트웨어와 하드웨어의 경계를 정리한다.
5. 인터럽트·DMA·스토리지 구조를 묶어 실제 서비스 병목 분석 문제로 확장한다.

## 핵심 개념

- 컴퓨터구조는 명령어가 CPU에서 실행되고, 메모리 계층과 입출력 장치가 이를 보조하는 전체 흐름을 다룬다.
- 성능은 `CPU time = Instruction Count × CPI × Clock Cycle Time`으로 설명할 수 있으며, 명령어 수·명령어당 평균 사이클·클럭 주기 중 무엇을 줄이는지 구분해야 한다.
- 금융권 시스템에서는 처리량, 지연시간, 장애 복구 관점에서 CPU 파이프라인, 캐시, 인터럽트, DMA를 함께 이해해야 한다.

시험 답안에서는 아래 두 식을 함께 기억하면 설명 폭이 넓어진다.

```text
CPU time = Instruction Count × CPI × Clock Cycle Time
AMAT = Hit Time + Miss Rate × Miss Penalty
```

- 첫 번째 식은 CPU 내부 병목을, 두 번째 식은 메모리 계층 병목을 설명할 때 유용하다.
- 파이프라인 개선은 주로 CPI를 줄이는 방향이고, 캐시 적중률 개선은 miss penalty 체감 시간을 줄이는 방향이다.
- 분기 예측 실패, 캐시 미스, 인터럽트 폭주처럼 서로 다른 병목이 한 문제 안에서 같이 등장할 수 있다는 점이 금융공기업 필기에서 자주 활용된다.

빠른 복습용 체크포인트

- [ ] CPU time 식의 각 항목이 무엇을 의미하는지 설명할 수 있다.
- [ ] 캐시/TLB/I/O 병목을 각각 다른 원인으로 구분할 수 있다.
- [ ] DMA와 인터럽트가 처리량과 CPU 점유율에 미치는 차이를 말할 수 있다.
- [ ] RISC/CISC 비교를 파이프라인과 코드 밀도 관점으로 연결할 수 있다.

## 약어 풀이

- CISC: Complex Instruction Set Computer, 복합 명령어 집합 컴퓨터
- CPU: Central Processing Unit, 중앙처리장치
- DMA: Direct Memory Access, 직접 메모리 접근
- IT: Information Technology, 정보기술
- RISC: Reduced Instruction Set Computer, 축소 명령어 집합 컴퓨터
- TLB: Translation Lookaside Buffer, 주소 변환 캐시
- AMAT: Average Memory Access Time, 평균 메모리 접근 시간
