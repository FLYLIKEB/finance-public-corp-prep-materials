## 2009 전산학술 발췌

보안, 자료구조, 운영체제, 논리회로, 데이터베이스 복구, 네트워크, 웹 보안, 알고리즘, 병렬성능, 교착상태가 한 회차에 섞여 있는 종합형 발췌본이다.

### I. 객관·선택형 중심 발췌

#### 1. PKI 메시지 암호화와 전자서명 키 매칭

전자서명을 포함한 메시지를 송수신할 때 다음 작업에 어떤 키가 대응되는지 묻는 문제다.

- 메시지 암호화
- 전자서명 암호화
- 메시지 복호화
- 전자서명 복호화

#### 2. 수식의 후위표기식 변환

`cos`, `sin`을 단항 연산자, `-`, `^`, `*`, `=`를 이항 연산자로 두고 주어진 식을 **올바른 후위표기식(Postfix expression)** 으로 고르는 문제다.

#### 3. SJF 스케줄링 평균 반환시간

도착 시각과 수행 시간이 주어진 `P1~P5` 프로세스에 대해 **SJF(Shortest Job First)** 스케줄링의 평균 반환시간을 계산하는 문제다.

![2009 전산학술 — RS 플립플롭 상태 전이 그림](https://raw.githubusercontent.com/FLYLIKEB/finance-public-corp-prep-materials/main/%EC%A4%80%EB%B9%84%EC%9E%90%EB%A3%8C/%ED%95%9C%EA%B5%AD%EC%9D%80%ED%96%89%20%EA%B8%B0%EC%B6%9C/pdf/html/09.%20%EC%A0%84%EC%82%B0%ED%95%99%EC%88%A0%282009%29.html/bindata/BIN0001.bmp)

#### 4. RS 플립플롭 논리회로 상태표 완성

상태 전이 그림을 보고 `RS(Reset-Set) 플립플롭`으로 회로를 설계할 때,

- 현재 상태
- 입력 `X`
- 다음 상태
- 플립플롭 입력 `SA, RA, SB, RB`

사이의 빈칸을 채우는 문제다.

#### 5. 로그 기반 복구의 UNDO/REDO 필요 조건

다음 두 조건에서 `UNDO`, `REDO`가 각각 필요한지 판단하는 문제다.

- `UNCOMMIT` 자료가 항상 메모리에만 대기하는 경우
- `COMMIT` 자료가 항상 디스크에 저장되는 경우

### II. 단답·서술형 발췌

#### 1. 이진검색트리 은행잔고 합 재귀 메서드 완성

`BinaryNode` 클래스가 주어졌을 때, 모든 노드의 `balance` 합을 구하는 `balanceSum(BinaryNode t)` 메서드를 **재귀호출**로 완성하는 문제다.

![2009 전산학술 — 브리지 구성도](https://raw.githubusercontent.com/FLYLIKEB/finance-public-corp-prep-materials/main/%EC%A4%80%EB%B9%84%EC%9E%90%EB%A3%8C/%ED%95%9C%EA%B5%AD%EC%9D%80%ED%96%89%20%EA%B8%B0%EC%B6%9C/pdf/html/09.%20%EC%A0%84%EC%82%B0%ED%95%99%EC%88%A0%282009%29.html/bindata/BIN0002.bmp)

#### 2. 브리지 포워딩 테이블 학습 과정

브리지 `B1`, `B2`가 있는 네트워크 구성도에서 다음 프레임 전송 순서가 주어졌을 때,

- `C → A`
- `F → E`
- `E → F`
- `D → B`

각 브리지의 **Forwarding table** 상태를 완성하는 문제다.

#### 3. CRC 코드 계산

생성 다항식 `G(x)=X^4 + X^3 + 1`을 사용하여 메시지 `110011`의 **CRC 코드를 modulo-2 연산으로 계산하는 과정과 결과**를 쓰는 문제다.

#### 4. SOA와 웹 2.0 비교

`SOA(Service-Oriented Architecture)`와 `웹 2.0`의 지향점과 활용 관점을 비교하는 문제다.

#### 5. XSS 공격 원리 설명

웹 해킹 기법 중 `XSS(Cross Site Scripting)`의 동작 원리를 설명하는 문제다.

#### 6. Agile 개발 방법론 설명

`Agile` 개발 방법론의 핵심 철학과 전통적 개발 방식 대비 특징을 정리하는 문제다.

### III. 응용·계산형 발췌

#### 1. MASS(Maximum Alternating Sum Subsequence)

양수 수열 `S`에 대해 **홀수항의 합 - 짝수항의 합**을 최대로 만드는 부분수열 `MASS`를 정의하고 다음을 묻는다.

- 주어진 수열의 `MASS`와 그 값 계산
- `MASS` 값을 구하는 동적 계획법 알고리즘 빈칸 채우기
- 수열에 음수가 포함될 때 알고리즘의 변경 여부 설명

#### 2. 클러스터 컴퓨팅 성능 비교

예산 `1억원`으로 금융 시뮬레이션 프로그램 `P`를 돌릴 때,

- `A사`와 `B사` 견적의 `IC`, `CPI`, `Clock frequency`, 장비 단가가 주어지고
- 각 구성에서 **초당 프로그램 수행 횟수**를 계산한 뒤
- 어느 구성이 더 나은지와 **성능 배수**를 쓰는 문제다.

#### 3. 은행원 알고리즘(Banker’s algorithm)

프로세스 `P0~P3`와 자원 `A, B`의 할당/최대요구/가용량 표가 주어졌을 때,

- 각 프로세스의 `Need` 계산
- 시스템의 `Safe state` 여부 설명
- `P1`의 최대 요구량 변경 요청을 수용할 수 있는지 판단

을 요구한다.
