# 06-02. CPU 스케줄링

## 핵심 개념

- 스케줄링은 CPU 시간을 프로세스에 배분하는 정책이다.
- 평균 대기시간과 반환시간이 계산 문제의 핵심이다.
- 선점형은 실행 중인 프로세스를 중단할 수 있다.

## 쉽게 이해하기

- CPU 스케줄링은 한 명의 상담원이 여러 고객을 어떤 순서로 처리할지 정하는 문제와 같다.
- 먼저 온 사람부터 받을지, 짧은 상담부터 끝낼지, 오래 기다린 사람을 우선할지에 따라 평균 대기시간이 달라진다.
- 계산 문제에서는 간트 차트를 그려 시작·종료 시간을 표시하면 실수를 줄일 수 있다.
