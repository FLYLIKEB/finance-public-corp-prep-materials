# 17. 클라우드·분산 시스템 심화

금융IT 인프라는 온프레미스, 클라우드, 컨테이너, 메시지 큐, 마이크로서비스가 함께 쓰이는 방향으로 확장되고 있다. 이 장은 필기 보완과 심화 면접 대비를 위해 클라우드 서비스 모델, 컨테이너 오케스트레이션, 분산 시스템 이론, 메시징, MSA를 연결한다.

## 핵심 개념

- 클라우드는 자원을 필요할 때 할당하고 사용량 기반으로 비용을 지불하는 인프라 운영 방식이다.
- 분산 시스템은 여러 노드가 네트워크로 협력해 하나의 서비스를 제공하지만, 네트워크 지연·장애·일관성 문제가 항상 따라온다.
- 금융권에서는 혁신성과 확장성뿐 아니라 보안, 규제, 장애 대응, 감사 추적성을 함께 설계해야 한다.

## 약어 풀이

- API: Application Programming Interface, 응용 프로그램 인터페이스
- CAP: Consistency, Availability, Partition Tolerance, 일관성·가용성·분할 내성
- MSA: Microservice Architecture, 마이크로서비스 아키텍처
- SaaS: Software as a Service, 서비스형 소프트웨어
