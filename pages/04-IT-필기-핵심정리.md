## 중요도 기준

| 표시 | 중요도 | 의미 |
| --- | --- | --- |
| ★★★ | 상 | 전산직 필기 단골 문제. 개념과 예시를 모두 확실히 암기해야 함 |
| ★★ | 중 | 2회 이상 중복 출제된 문제 |
| ★ | 하 | 출제 이력이 있으나 기본 개념 위주로 알면 되는 문제 |

> 특히 중요한 개념은 원문에서 빨간색으로 표기된 항목입니다.

## 학습 전략

전공 필기는 정말 **아는 만큼 풉니다.** 다만 간혹 터무니없이 어려운 문제가 출제될 때가 있는데, 그런 문제는 대부분의 수험생이 풀기 어렵습니다.

따라서 핵심은 **선택과 집중**입니다. 정처기 책 전체를 훑기보다, 아래 빈출 주제를 우선순위에 따라 반복 학습하세요.

### 시각자료 활용법

| 학습 방식 | 우선 적용 개념 | 활용 포인트 |
| --- | --- | --- |
| 표로 암기 | 비교형 개념 | 선지에서 바뀌기 쉬운 키워드만 빠르게 확인 |
| 그림으로 이해 | 구조·흐름형 개념 | 구성요소의 위치와 데이터 흐름을 먼저 기억 |
| 계산으로 연습 | 스케줄링·비용산정·순회 | 공식보다 예시 풀이 순서를 반복 |

```text
1회독: ★★★ 개념의 표만 빠르게 암기
  ↓
2회독: 그림/흐름도로 구조 이해
  ↓
3회독: 계산 예시와 기출 선지 판단 연습
```

> **암기 포인트**   표는 객관식 선지 판단용, ASCII 그림은 구조형 문제 대비용, 계산 예시는 시간 단축용으로 활용하세요.

## 약어 풀이

- CBDC: Central Bank Digital Currency, 중앙은행 디지털화폐
- CISC: Complex Instruction Set Computer, 복합 명령어 집합 컴퓨터
- GPU: Graphics Processing Unit, 그래픽 처리 장치
- HTTP: HyperText Transfer Protocol, 하이퍼텍스트 전송 프로토콜
- IT: Information Technology, 정보기술
- RAID: Redundant Array of Independent Disks, 독립 디스크 중복 배열
- RISC: Reduced Instruction Set Computer, 축소 명령어 집합 컴퓨터
- SQL: Structured Query Language, 구조화 질의어
- TCP: Transmission Control Protocol, 전송 제어 프로토콜
- UDP: User Datagram Protocol, 사용자 데이터그램 프로토콜
