# 08-04. 라우팅과 서브넷

> 학습 목적: 라우팅과 서브넷 계산의 기본을 정리한다.
> 관련 기출: [05-11-네트워크-기출-모음](05-11-네트워크-기출-모음.md)
> 연결 핵심정리: [04-4-네트워크-프로토콜-보안](04-04-네트워크-프로토콜-보안.md)

## 핵심 개념

- 라우팅은 목적지까지 경로를 선택하는 과정이다.
- 서브넷은 네트워크를 더 작은 단위로 나누는 방식이다.
- CIDR 표기와 호스트 수 계산을 함께 연습한다.


### 서술형 확장 개념

- Distance Vector 라우팅은 이웃에게 거리 정보를 주고받아 최단 경로를 갱신한다. 구현은 단순하지만 count-to-infinity 문제가 가능하며 RIP가 대표 예다.
- Link State 라우팅은 각 라우터가 링크 상태를 전체에 전파하고 각자 Dijkstra 알고리즘으로 최단 경로를 계산한다. OSPF가 대표적이며 수렴이 빠르고 대규모 네트워크에 적합하다.
- BGP는 AS 간 정책 기반 라우팅 프로토콜이다. 인터넷 전체 경로 선택은 단순 최단거리보다 조직 간 정책, 경로 속성, 안정성을 함께 고려한다.
- CIDR `/n`에서 네트워크 비트는 n개, 호스트 비트는 `32-n`개다. 예를 들어 `/26`은 호스트 비트가 6개라 주소 64개를 만들고, 일반적인 IPv4 서브넷에서는 네트워크 주소와 브로드캐스트 주소를 제외해 사용 가능한 호스트는 62개다.

| 장비 | 계층 | 역할 |
| --- | --- | --- |
| Hub | 1계층 | 신호를 모든 포트로 반복 |
| Switch | 2계층 | MAC 주소 기반 프레임 전달 |
| Router | 3계층 | IP 기반 네트워크 간 전달 |
| L4/L7 Load Balancer | 4/7계층 | 포트 또는 응용 메시지 기준 부하분산 |

## 쉽게 이해하기

- 라우팅은 목적지까지 어떤 길로 갈지 정하는 내비게이션 역할이다.
- 서브넷은 큰 사무실을 팀별 구역으로 나누는 것과 비슷하다. 네트워크를 작게 나누면 관리와 보안이 쉬워진다.
- CIDR 문제는 주소 범위와 사용 가능한 호스트 수를 계산하는 연습이 중요하다.
