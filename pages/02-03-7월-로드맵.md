# 7월: 전산학 2회독 + 공고 대응

> **7월 핵심 이벤트**: 한국은행 2027년도 G5 공고 예상 (07 말~08 초). 공고 뜨는 즉시 서류 작업 전환.

### 목표

- [ ] 전산학 2회독
- [ ] 한국은행 기출 4개년 이상 풀이
- [ ] 작년 한은 자소서 수정본 완성 — **공고 문항 확인 후 즉시 제출 가능한 상태**
- [ ] 자소서 문장별 예상 꼬리질문 작성
- [ ] 주요 기관 공통 자소서 소재 추출
- [ ] NCS 시간관리 루틴 확립

### 주차별

| 기간 | 할 일 | 채용 이벤트 |
|---|---|---|
| 7/1~7/15 | 전공 2회독 시작, 한은 기출 3개년, 작년 자소서 1차 수정 | 기보 필기 결과 확인 예정 |
| 7/16~7/31 | 전공 2회독 완료, SQL 중급, 자소서 제출본 완성 대기 | **한은 공고 예상 (07 말): 공고 뜨면 즉시 서류 작업 전환** |

### 공고 대응 프로세스 (한은 공고 시)

| 단계 | 행동 |
|---|---|
| 공고 확인 | 문항·전형 변경사항 체크, 작년 대비 차이점 파악 |
| 자소서 수정 | 작년 합격본 기반으로 문항에 맞춰 소폭 수정 |
| 제출 | 접수 마감일 3일 전까지 제출 (예상 마감: 08 초) |
| 복귀 | 제출 완료 후 즉시 필기 준비로 복귀 |

### 자소서 수정 범위

| 구분 | 처리 |
|---|---|
| 구조 | 작년 합격본 유지 |
| 문항 | 올해 문항만 반영 |
| 경험 | 신규 경험/성과만 추가 |
| 표현 | 중앙은행 IT, 지급결제, 안정성, 보안 강화 |
| 방어 | 모든 문장을 면접에서 실제 경험으로 설명 가능하게 정리 |
| 연결 | 프로젝트/실무 경험을 지급결제·금융안정·통계/정책 분석 중 하나와 연결 |
| 검증 | 과장된 수치·검증 불가 사례 제거 |
| 시간 | 총 준비시간 5% 이내, 단 면접 방어 메모는 별도 누적 |
