# 나의 금융공기업 IT직군 준비 프로필

작성일: 2026-06-08

## 목표

- 금융공기업 IT직군 취업 준비
- 필기시험 대비가 핵심 준비 과제

## 현재 배경

- 전공 여부: 비전공자
- 실무 경험: 백엔드 실무 경험 2년
- 기존 학습 경험:
  - 약 3년 전, 면접용 IT 질문 리스트를 암기한 경험 있음
  - 전산/IT 면접 개념에 대한 과거 노출 경험은 있으나, 현재는 재정리와 복습이 필요할 가능성이 있음

## 시험 일정 관련 정보

- 필기시험 예상 시점: 9월 13일 전후로 예상
- 근거: 작년 기준 필기 일정이 9월 13일에 진행된 것으로 추정
- 주의: 실제 2026년 일정은 기관별 공고 확인 필요

## 준비 전략상 시사점

### 강점

- 백엔드 실무 경험 2년으로 인해 다음 영역에서 상대적 강점 가능성 있음:
  - 서버 구조
  - API 설계
  - 데이터베이스 실무 감각
  - 장애 대응/운영 경험
  - 실무 기반 면접 답변 구성
- 과거 IT 면접 질문 리스트를 암기한 경험이 있어 기본 개념 재진입 속도가 빠를 가능성 있음

### 보완 필요 영역

- 비전공자이므로 전산학 필기 과목을 체계적으로 정리해야 함
- 과거 암기 지식은 3년 전 기준이므로 최신화 및 장기기억화 필요
- 금융공기업 필기 특성상 실무 경험만으로는 부족할 수 있으므로 이론 중심 대비 필요

## 우선 준비 과목 후보

1. 운영체제
2. 데이터베이스
3. 네트워크
4. 자료구조/알고리즘
5. 소프트웨어공학
6. 정보보안
7. NCS
8. 기관별 금융/디지털 이슈 및 면접 대비

## 현재 기준 준비 방향

- 단순 암기보다 `필기용 개념 정리 + 기출 기반 문제풀이 + 면접 답변화`를 함께 진행
- 백엔드 실무 경험을 전공 개념과 연결해 면접 경쟁력으로 전환
- 9월 중순 필기를 기준으로 역산하여 학습 계획 수립
