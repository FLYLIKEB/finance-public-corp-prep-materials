# 09-01-01. 스택과 큐

> 학습 목적: LIFO와 FIFO를 문제 상황에 적용한다.

## 핵심 개념

- 스택(stack)은 LIFO(Last In, First Out) 구조다. 가장 나중에 들어온 요소가 먼저 나간다.
- 큐(queue)는 FIFO(First In, First Out) 구조다. 먼저 들어온 요소가 먼저 나간다.
- DFS(Depth-First Search)는 논리적으로 스택과 연결해서 이해하고, BFS(Breadth-First Search)는 큐와 연결해서 이해한다.
- 기본 연산과 시간복잡도(평균/암시): 대부분의 스택/큐 연산은 O(1)이다(적절한 구현 시).

## 쉽게 이해하기

- 스택은 접시 쌓기: 접시를 한 장씩 쌓아서 가장 위에 있는 접시를 먼저 꺼낸다.
- 큐는 줄서기: 줄 앞 사람부터 차례대로 처리한다.
- 재귀 호출은 내부적으로 호출 스택(call stack)을 사용하므로, 재귀 문제는 스택 시맨틱으로 생각하면 된다.

## 연산 정리 (핵심 연산과 의미)

- 스택
  - push(x): 요소 x를 스택의 맨 위에 추가한다.
  - pop(): 맨 위 요소를 제거하고 반환한다. (언더플로우 주의)
  - peek()/top(): 맨 위 요소를 제거하지 않고 확인한다.
  - isEmpty(), size()

- 큐
  - enqueue(x) 또는 offer(x): 요소 x를 큐의 뒤(리어)에 추가한다.
  - dequeue() 또는 poll(): 앞(프런트)의 요소를 제거하고 반환한다. (언더플로우 주의)
  - peek()/front(): 앞 요소를 제거하지 않고 확인한다.
  - isEmpty(), size()

## 구현 방식 비교

- 배열 기반
  - 스택: 배열 끝을 top으로 사용하면 push/pop이 O(1).
  - 큐: 배열 앞에서 제거하면 O(n) (요소 이동 필요). 이를 해결하려면 원형 버퍼(circular buffer)를 사용해 O(1)로 만든다.

- 연결 리스트 기반
  - 스택: 단일 연결 리스트의 머리를 top으로 사용하면 push/pop이 O(1).
  - 큐: 연결 리스트에서 head와 tail을 모두 유지하면 enqueue/dequeue 모두 O(1).

- 언어별 표준 라이브러리
  - Python: list로 스택 구현 가능(push/pop), collections.deque로 큐/덱 구현 권장(양쪽 끝에서 O(1)).
  - Java: Stack, ArrayDeque, LinkedList 등(문제 유형에 맞게 선택).

## 구현 예시 (의사코드 / Python 스타일)

스택 (파이썬 list 사용):

```
# push O(1), pop O(1)
stack = []
stack.append(1)   # push
x = stack.pop()   # pop
if stack:
    top = stack[-1]  # peek
```

원형 큐 (개념적 의사코드):

```
# capacity가 정해진 원형 큐
arr = [None] * capacity
head = 0
tail = 0
size = 0

def enqueue(x):
    if size == capacity:
        raise OverflowError
    arr[tail] = x
    tail = (tail + 1) % capacity
    size += 1

def dequeue():
    if size == 0:
        raise IndexError
    val = arr[head]
    head = (head + 1) % capacity
    size -= 1
    return val
```

큐 (파이썬 collections.deque 사용 예):

```
from collections import deque
q = deque()
q.append(1)   # enqueue
x = q.popleft()  # dequeue
```

## 시간/공간 복잡도 요약 (대표적 연산)

| 구조 | 연산 | 평균 시간복잡도 | 비고 |
|---|---:|---:|---|
| 스택 (배열/리스트) | push/pop/peek | O(1) | 동적 배열 리사이징은 암묵적 오버헤드가 있을 수 있음 |
| 큐 (원형 버퍼/연결리스트) | enqueue/dequeue/peek | O(1) | 단순 배열에서 앞 제거는 O(n)임 |
| 덱 (deque) | 양쪽 끝 추가/제거 | O(1) | 슬라이딩 윈도우, 단기 제한 구조에 유리 |

공간: 저장하는 n개의 요소에 대해 O(n).

## 출제 포인트 (시험/면접에서 자주 묻는 것)

- 스택/큐의 정의와 LIFO/FIFO 구분을 서술하라.
- 스택과 큐의 기본 연산을 쓰고 시간복잡도를 설명하라.
- 배열 기반 큐의 단점을 설명하고 그 해결책(원형 큐)을 설명하라.
- 재귀와 스택의 관계를 설명하라(콜 스택 활용).
- 스택을 이용한 괄호 검사, 중위-후위 변환, 후위식 계산 문제 출제.
- 큐를 이용한 BFS(너비 우선 탐색), 레벨 순회, 최단 거리(비가중치 그래프) 문제 출제.
- 덱(deque)을 이용한 슬라이딩 윈도우 최대값 문제(시험 빈도 높음).

## 실전 연습 문제 (시험 대비형)

1) 괄호 짝 맞추기
   - 문제: 문자열에 포함된 괄호 '()','[]','{}'가 올바르게 짝을 이루는지 검사하라.
   - 풀이 아이디어: 여는 괄호를 스택에 push, 닫는 괄호가 나오면 스택 pop 후 짝 확인. 끝에 스택이 비어 있지 않으면 실패.
   - 시간/공간: O(n) / O(n)

2) 후위 표기식 (RPN) 평가
   - 문제: 공백으로 구분된 후위 표기식을 평가하라(숫자와 + - * / 연산자).
   - 풀이 아이디어: 토큰을 왼쪽부터 읽으며 숫자는 스택에 push, 연산자는 스택에서 두 개 pop 후 계산한 결과를 push. 끝에 스택의 값이 결과.
   - 시간/공간: O(n) / O(n)

3) 문자열 뒤집기 (스택 사용)
   - 문제: 스택을 사용해 문자열을 뒤집어라.
   - 풀이 아이디어: 문자들을 스택에 push 후 pop 하여 새 문자열 구성.
   - 시간/공간: O(n) / O(n)

4) BFS로 최단 경로 (비가중치 그래프)
   - 문제: 시작 정점에서 모든 정점까지의 최단 거리를 구하라.
   - 풀이 아이디어: 큐를 사용한 BFS, 방문 배열과 거리 배열 관리.
   - 시간/공간: O(V+E) / O(V)

5) DFS (스택으로 반복 구현)
   - 문제: 재귀 없이 스택을 사용해 DFS를 구현하라.
   - 풀이 아이디어: 시작 노드를 스택에 push, pop한 노드의 인접 노드들을 push(방문 검사 필요).
   - 주의: 인접 노드 push 순서에 따라 방문 순서가 달라질 수 있음.

6) 슬라이딩 윈도우 최대값 (덱 활용)
   - 문제: 길이 k인 윈도우를 오른쪽으로 한 칸씩 이동시키며 각 윈도우의 최대값을 구하라.
   - 풀이 아이디어: 인덱스를 보관하는 덱을 사용해 현재 윈도우에서 최대를 O(1)로 유지.
   - 시간/공간: O(n) / O(k)


## 자주 틀리는 실수 및 팁

- 큐를 단순 배열로 구현할 때, dequeue시 모든 요소를 옮겨야 하는 구현은 비효율적이다 — 원형 버퍼 사용을 떠올려라.
- pop 시 빈 스택/큐에 대한 예외처리를 반드시 생각하라(문제에서는 보장되는 경우도 있으니 문제 조건 확인).
- 스택을 이용한 알고리즘에서는 peek/top을 자주 사용하므로 제거(pop)와 단순 조회(peek)를 혼동하지 말 것.
- BFS/DFS의 목적을 문제에 맞춰 판단: "최단 거리(간선 가중치 1)"나 "최소 단계"라면 BFS, "모든 경로 탐색/백트래킹"이나 "특정 조건을 깊게 탐색"이라면 DFS.
- 재귀 깊이가 깊어 스택 오버플로우가 우려될 경우 반복(명시적 스택)으로 변환을 고려하라.

## 요약 포인트 (시험 직전 암기용)

- 스택 = LIFO, push/pop/peek, 연산 대부분 O(1).
- 큐 = FIFO, enqueue/dequeue/peek, 원형 버퍼로 구현하면 O(1).
- 재귀는 콜 스택 사용 → 스택 개념 응용.
- 괄호 검사, 후위식 계산 → 스택. BFS/레벨탐색/최단경로(비가중치) → 큐.
