# 11-2-2. 단위-통합-인수테스트

> 학습 목적: 테스트 단계별 목적을 구분한다.
> 관련 기출: [05-13-알고리즘-기출-모음](05-13-알고리즘-기출-모음.md)
> 연결 핵심정리: [04-3-소프트웨어공학-운영체제-컴퓨터구조](04-3-소프트웨어공학-운영체제-컴퓨터구조.md)

## 핵심 개념

- 단위 테스트는 개별 모듈을 검증한다.
- 통합 테스트는 모듈 간 인터페이스를 검증한다.
- 인수 테스트는 사용자 요구 충족 여부를 확인한다.

## 쉽게 이해하기

- 단위 테스트는 부품 하나가 제대로 작동하는지 보는 검사다.
- 통합 테스트는 부품들을 연결했을 때 서로 잘 맞는지 보는 검사다.
- 인수 테스트는 최종 사용자가 요구한 기능을 만족하는지 확인하는 검사다.

## 빈출 포인트

- 정의와 특징을 구분하는 객관식 문항
- 비슷한 개념 간 차이 비교
- 실제 기출 키워드와 연결한 빠른 복습

## 오답 포인트

- 용어의 이름보다 적용 조건을 먼저 확인한다.
- 예외와 반례가 있는 선지를 주의한다.
- 계산형 주제는 중간 과정을 생략하지 않는다.
