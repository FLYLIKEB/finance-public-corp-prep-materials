## 빅데이터

> 중요도: **상** (★★★)

### 1. 빅데이터 특징
- 3V : Volume, Velocity, Variety
- 5V : Volume, Velocity, Variety, Veracity, Value
- 7V : Volume, Velocity, Variety, Veracity, Value, Variability, Visualization

#### 3V/5V/7V 비교표

| 구분 | 구성 요소 | 핵심 의미 |
| --- | --- | --- |
| 3V | Volume, Velocity, Variety | 양·속도·다양성. 가장 기본으로 출제 |
| 5V | 3V + Veracity, Value | 신뢰성·가치가 추가됨 |
| 7V | 5V + Variability, Visualization | 변동성·시각화까지 포함 |

```text
3V: Volume + Velocity + Variety
5V: 3V + Veracity + Value
7V: 5V + Variability + Visualization
```

> **출제 경향**   빅데이터 특징의 3V 뿐만 아니라 5V 도 물어보고 있는 문제가 많이 출제됩니다. 혹시
모르니 7V 까지는 숙지를 하셔야합니다.

### 2. 빅데이터 분석 방법론 순서
- 기획 - 데이터준비 - 분석 - 시스템 구현 - 평가

```text
[기획] → [데이터 준비] → [분석] → [시스템 구현] → [평가]
```

> **암기 포인트**   순서형 객관식에서는 `기획`이 가장 먼저, `평가`가 가장 마지막입니다.

> **출제 경향**   객관식으로 은근 자주 출제됩니다. 각 방법론의 특징까지는 출제되지 않으니 순서만
기억하세요.

### 3. 빅데이터 종류

#### 비정형데이터 (Unstructured Data)
- **정의:** 고정된 구조나 형식이 없는 데이터로, 분석하기 위해서는 추가적인 처리 필요
- **예시:** 텍스트 문서, 이메일, 소셜 미디어 게시물, 이미지, 동영상, 오디오 파일 등.
- **특징:** 데이터의 형식이 일정하지 않아서 정형화된 테이블에 바로 저장하거나 분석하기
  어려움

#### 반정형데이터 (Semi-structured Data)
- **정의:** 고정된 스키마가 없지만, 일정한 구조를 가지고 있어 정형화된 데이터로 변환하기 쉬운
  데이터
- **예시:** XML, JSON, YAML, 로그 파일 등.
- **특징:** 태그나 키-값 쌍 등의 형식을 사용하여 구조화되어 있으며, 데이터베이스로 변환하기
  비교적 용이

#### 정형데이터 (Structured Data)
- **정의:** 고정된 필드에 저장된 데이터로, 테이블 형식으로 체계적으로 구성된 데이터
- **예시:** 관계형 데이터베이스, 스프레드시트, CSV 파일 등.
- **특징:** 데이터가 행과 열로 구성되어 있으며, 쉽게 검색하고 분석

#### 데이터 유형 비교표

| 유형 | 구조 | 대표 예시 | 선지 판단 포인트 |
| --- | --- | --- | --- |
| 정형 | 행·열 구조 고정 | RDB, CSV, 스프레드시트 | 테이블에 바로 저장 가능 |
| 반정형 | 스키마는 유연하지만 태그/키 존재 | XML, JSON, YAML, 로그 | 구조는 있으나 고정 테이블은 아님 |
| 비정형 | 정해진 구조 없음 | 이미지, 영상, 음성, 문서 | 분석 전 전처리 필요 |

> **출제 경향**   각 데이터의 개념을 묻는 문제보단 예시에 대한 객관식 문제가 자주 출제됩니다.
’1. 반정형데이터에는 이미지, XML 이 있다(x)’ 이런식으로 출제됩니다.

## 블록체인

> 중요도: **상** (★★★)

### 1. 퍼블릭 블록체인 vs 프라이빗 블록체인

| 구분 | 퍼블릭 블록체인 | 프라이빗 블록체인 |
| --- | --- | --- |
| 참여 | 누구나 참여 가능 | 허가된 사용자만 참여 |
| 통제 | 탈중앙화 | 특정 조직이 통제 |
| 투명성 | 거래 기록 공개 | 참여자 범위 내 공개 |
| 처리 속도 | 상대적으로 느림 | 상대적으로 빠름 |
| 대표 키워드 | 개방성, 검열 저항성 | 접근 제한, 프라이버시, 효율성 |

```text
퍼블릭: 누구나 참여 → 검증자 많음 → 투명하지만 느림
프라이빗: 허가된 참여자 → 통제 가능 → 빠르지만 중앙화 성격
```

#### 퍼블릭 블록체인 특징
- 탈중앙화: 누구나 네트워크에 참여할 수 있으며, 모든 참여자는 동일한 권한을 가짐
- 투명성: 모든 거래 기록이 공개되어 누구나 확인 가능
- 보안성: 다수의 참여자가 거래를 검증하고, 네트워크의 안전성 보장
- 검열 저항성: 중앙 권한이 없으므로 거래가 검열되기 어려움.
- 확장성 문제: 트랜잭션 처리 속도가 느리고, 대규모 사용자 수용에 어려움.
- 분산 합의 알고리즘: 주로 PoW(Proof of Work)나 PoS(Proof of Stake)와 같은 알고리즘을
  사용

#### 프라이빗 블록체인 특징
- 중앙화: 특정 그룹이나 조직이 네트워크를 관리하고 통제
- 접근 제한: 네트워크 참여자가 제한되어 있으며, 초대받은 사용자만 참여 가능
- 프라이버시 보호: 거래 기록은 네트워크 참여자에게만 공개되며, 외부에서는 접근불가
- 높은 처리 속도: 제한된 참여자로 인해 트랜잭션 처리 속도가 빠름.
- 유연성: 중앙 관리자가 네트워크 규칙을 변경할 수 있어 유연한 운영 가능

> **출제 경향**   퍼블릭 볼록체인, 프라이빗 블록체인에 대한 설명으로 옳지 않은 것은? 같은 특징에
대한 문제가 다수 출제되고 있어, 필수적으로 이해 및 암기하셔야합니다.

### 2. 블록체인 합의 알고리즘

#### Proof of Work (PoW)
- **정의:** 블록체인 네트워크에서 새로운 블록을 추가하기 위해 채굴자들이 복잡한 수학 문제를
  해결하는 합의 알고리즘
- **작동 방식:** 채굴자들은 주어진 해시 값을 찾기 위해 무작위로 값을 대입하는 작업을
  반복합니다. 이 과정을 통해 적절한 해시 값을 가장 먼저 찾는 채굴자가 새로운 블록을
  추가하고, 보상으로 암호화폐를 받습니다.
- **장점:** 높은 보안성 제공.
- **단점:** 높은 에너지 소비와 비용 발생

#### Proof of Stake (PoS)
- **정의:** PoS 는 블록 생성 권한을 보유하고 있는 암호화폐의 양(지분)에 따라 분배하는 합의
  알고리즘
- **작동 방식:** PoS 에서는 암호화폐를 많이 보유하고 있는 사용자가 블록을 생성할 확률이
  높아집니다. 새로운 블록을 추가하기 위해서는 네트워크 참여자들이 자신의 지분을 '
  스테이킹'해야 하며, 그 중 하나가 무작위로 선택되어 블록을 생성합니다.
- **장점:** 에너지 효율이 높고, 환경에 미치는 영향이 적음.
- **단점:** 암호화폐를 많이 보유한 사용자가 더 많은 권한을 가지게 되어, 탈중앙화의 원칙이
  약화될 가능성 존재

#### PoW vs PoS 비교표

| 구분 | PoW | PoS |
| --- | --- | --- |
| 기준 | 연산 작업량 | 보유 지분 |
| 참여자 | 채굴자 | 검증자 |
| 장점 | 검증 난도가 높아 보안성 강함 | 에너지 효율이 높음 |
| 단점 | 전력 소모 큼 | 지분 집중 위험 |
| 대표 암기어 | 채굴, 해시, 전기 | 스테이킹, 지분, 효율 |

→ 자주 출제되지는 않지만 아주 가끔씩 출제되므로 면접까지 진출하고싶다면 챙겨야하는 개념.
개념과 장단점정도만 간단하게 알아가면 됩니다.

(퍼블릭/프라이빗 블록체인 문제가 더 빈번하게 출제됨)

## 머신러닝

> 중요도: **상** (★★★)

### 1. 머신러닝 학습 종류

#### 지도 학습(Supervised Learning)
- **정의:** 입력 데이터와 해당 데이터의 정답(레이블)이 함께 제공되는 학습 방식.
- **예시:** 이미지에 있는 사물을 분류하거나 이메일을 스팸과 정상으로 분류.
- **알고리즘:** 회귀 분석, 의사결정 나무, 서포트 벡터 머신, 신경망 등.

#### 비지도 학습(Unsupervised Learning)
- **정의:** 정답이 없는 데이터를 통해 패턴을 학습하는 방식.
- **예시:** 고객 세그먼테이션, 이상 탐지, 데이터 차원 축소.
- **알고리즘:** 군집화(K-Means), 주성분 분석(PCA), 연관 규칙 학습 등.

#### 강화 학습(Reinforcement Learning)
- **정의:** 행동주체가 환경과 상호작용하면서 보상을 최대화하는 행동을 학습하는 방식.
- **예시:** 게임 플레이, 로봇 제어, 자율 주행.
- **알고리즘:** Q-러닝, 딥 Q-네트워크(DQN), 정책 경사법.

#### 머신러닝 학습 유형 비교표

| 학습 유형 | 정답 데이터 | 목표 | 대표 예시 | 대표 알고리즘 |
| --- | --- | --- | --- | --- |
| 지도 학습 | 있음 | 예측·분류 | 스팸 분류, 가격 예측 | 회귀, SVM, 의사결정나무 |
| 비지도 학습 | 없음 | 패턴 발견 | 고객 세분화, 이상 탐지 | K-Means, PCA, 연관 규칙 |
| 강화 학습 | 보상 | 최적 행동 선택 | 게임, 로봇, 자율주행 | Q-러닝, DQN |

```text
정답 있음 → 지도학습
정답 없음 → 비지도학습
보상을 최대화 → 강화학습
```

> **출제 경향**   머신러닝 학습종류에 대한 문제는 단골문제입니다. 각 학습이 어떤 특징을 가지고
있고, 어떤 알고리즘이 있는지 꼭!! 암기하셔야합니다.

### 2. 머신러닝 알고리즘

#### 지도학습

#### 선형 회귀 (Linear Regression)
- **정의:** 입력 변수와 출력 변수 사이의 선형 관계를 모델링하는 알고리즘
- **용도:** 연속적인 값을 예측할 때 사용. (예: 주택 가격 예측)
- **기법:** 데이터를 통해 최적의 직선을 찾기 위해 잔차 제곱합을 최소화

#### 로지스틱 회귀 (Logistic Regression)
- **정의:** 이진 분류 문제를 해결하기 위한 알고리즘 출력 값이 0 또는 1 로 한정
- **용도:** 스팸 이메일 분류, 질병 진단 등.
- **기법:** 시그모이드 함수를 사용하여 출력 값을 확률로 변환하고, 이 확률을 기반으로 분류

![로지스틱 회귀의 시그모이드 곡선](https://upload.wikimedia.org/wikipedia/commons/thumb/8/88/Logistic-curve.svg/500px-Logistic-curve.svg.png)
> 그림: 로지스틱 회귀는 선형 결합 결과를 시그모이드 함수에 통과시켜 0~1 사이의 확률로 해석한다.
> 출처: Wikimedia Commons, https://commons.wikimedia.org/wiki/File:Logistic-curve.svg

  의사결정 나무 (Decision Tree)
- **정의:** 데이터의 특성을 기반으로 분기하여 결정 규칙을 만드는 트리 구조의 알고리즘
- **용도:** 분류 및 회귀 문제 모두에 사용됩니다.
- **기법:** 각 노드에서 데이터를 가장 잘 분리할 수 있는 기준(정보 이득, 지니 불순도 등)을 찾아
  분기

  서포트 벡터 머신 (Support Vector Machine, SVM)
- **정의:** 데이터 포인트를 분리하는 최적의 초평면을 찾는 알고리즘
- **용도:** 주로 분류 문제에 사용되지만, 회귀 문제에도 적용 가능
- **기법:** 데이터를 고차원 공간으로 매핑하여 초평면을 찾고, 가장 가까운 데이터 포인트(서포트
  벡터)와의 거리를 최대화

  k-최근접 이웃 (k-Nearest Neighbors, k-NN)
- **정의:** 새로운 데이터 포인트를 가장 가까운 k 개의 이웃 데이터 포인트를 기반으로 분류하는
  알고리즘
- **용도:** 분류 및 회귀 문제 모두에 사용
- **기법:** 거리를 측정하여 k 개의 가장 가까운 이웃을 찾고, 이웃의 다수결이나 평균으로 결과를
  예측

  인공신경망 (Artificial Neural Networks)
- **정의:** 인간의 뇌 구조를 모방한 알고리즘으로, 다층 퍼셉트론을 사용하여 복잡한 패턴을 학습
- **용도:** 이미지 인식, 음성 인식, 자연어 처리 등 다양한 분야에 사용됨
- **기법:** 입력층, 은닉층, 출력층으로 구성된 네트워크를 통해 데이터를 학습하고, 역전파
  알고리즘을 사용하여 가중치 조정

#### 비지도학습

  군집화 (Clustering)
- **정의:** 데이터를 유사한 특성을 가진 그룹으로 나누는 알고리즘
- **용도:** 고객 세분화, 이미지 세그먼테이션, 이상 탐지 등.
- **기법:** 데이터 포인트 사이의 거리를 기반으로 유사한 데이터들을 묶어 그룹 형성.
  대표적인 알고리즘으로 K-평균(K-Means), 계층적 군집화(Hierarchical Clustering), DBSCAN
  등이 있음.

  차원 축소 (Dimensionality Reduction)
- **정의:** 고차원 데이터를 저차원 공간으로 변환하여 데이터의 중요한 구조를 유지하면서
  데이터의 차원을 줄이는 알고리즘
- **용도:** 데이터 시각화, 노이즈 제거, 특징 추출 등.
- **기법:** 주성분 분석(PCA) 등

  연관 규칙 학습 (Association Rule Learning)
- **정의:** 대규모 데이터셋에서 항목 간의 흥미로운 관계를 발견하는 알고리즘
- **용도:** 장바구니 분석, 추천 시스템 등.
- **기법:** Apriori 알고리즘, Eclat 알고리즘 등

#### 강화학습

  Q-러닝 (Q-Learning)
- **정의:** 모델 프리 강화학습 알고리즘으로, 상태-행동 쌍의 가치를 학습하여 최적의 정책 찾음
- **기법:** Q-테이블을 업데이트하여 각 상태-행동 쌍의 예상 보상을 학습

표기해둔 부분이 많이 출제되니 알고리즘 그림과 함께 숙지해두세요! 알고리즘을 사용한 예시도
정말 많이 나옵니다.

### 3. 가상현실 vs 증강현실 vs 혼합현실
- 가상현실 (Virtual Reality, VR):사용자가 컴퓨터로 생성된 완전한 가상 환경에 몰입하게 하는
  기술
- 증강현실 (Augmented Reality, AR):현실 세계에 가상 정보를 덧붙여서 보여주는 기술로,
  사용자가 실제 환경을 보면서 가상 객체나 정보를 함께 볼 수 있게 함
- 혼합현실 (Mixed Reality, MR):현실 세계와 가상 세계를 결합하여 상호작용할 수 있는
  새로운 환경을 만들어내는 기술로, 가상 객체가 실제 환경과 상호작용하는 것이 특징

| 구분 | 현실 세계 | 가상 객체 | 상호작용 | 암기 포인트 |
| --- | --- | --- | --- | --- |
| VR | 차단 | 전체 환경이 가상 | 가상 환경 내부 | 완전 몰입 |
| AR | 보임 | 현실 위에 덧붙임 | 제한적 | 현실 + 정보 |
| MR | 보임 | 현실과 결합 | 가능 | 현실과 가상이 서로 반응 |

> **출제 경향**   객관식 뿐만 아니라 주관식, 약술로도 출제가 되는 개념입니다. 각 개념에 대해 확실히
모르면 헷갈리기 정말 쉬운 개념입니다. 잘 숙지해야합니다.
