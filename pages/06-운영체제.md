## 복습 포인트

- 스케줄링 계산 문제
  - FCFS, SJF, HRN, RR 순으로 정의와 예제 풀이 방식(대기시간, 반환시간 계산)을 먼저 정리한다.
- 메모리 관리
  - 단편화(내부/외부), 페이징, 세그먼트의 차이를 비교 표로 만들어 암기한다.
- 교착상태
  - 발생 조건(상호배제, 점유와 대기, 비선점, 순환대기)과 해결 방법(예방, 회피, 탐지·복구)을 함께 정리한다.


## 한국은행 서술형 보강 범위

운영체제 서술형 답안은 일반적으로 "자원 관리 목적 → 커널 메커니즘 → 성능·안정성 trade-off" 순으로 기술하면 확장성과 일관성이 좋다. 프로세스/스레드, CPU 스케줄링, 동기화/교착상태, 가상메모리에 더해 시스템 콜, IPC, TLB, 페이지 교체, 파일 시스템, 디스크 스케줄링 등 관련 개념을 연결해서 설명할 수 있어야 한다.

| 영역 | 반드시 연결할 개념 |
| --- | --- |
| 프로세스 관리 | 시스템 콜, 커널 모드, IPC, 문맥교환 |
| CPU 관리 | 평가 지표, 선점/비선점, starvation과 aging |
| 동기화 | mutex, semaphore, monitor, Banker 알고리즘 |
| 메모리 | TLB, page fault, replacement, thrashing |
| 저장장치 | inode, journaling, contiguous/linked/indexed allocation, SCAN/C-SCAN |

## 약어 풀이

- CPU: Central Processing Unit, 중앙처리장치
- FCFS: First-Come, First-Served, 선입선처리
- HRN: Highest Response-ratio Next, 최고 응답률 우선
- SJF: Shortest Job First, 최단 작업 우선
