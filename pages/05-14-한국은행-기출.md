# 05-14. 한국은행 IT 기출

## 빠른 길잡이

한국은행 IT직군 기출은 **연도별 흐름**과 **주제별 반복 패턴**을 같이 봐야 효율이 좋다.  
이번 정리는 회차를 그대로 나열하는 대신, **연도 → 하위 카테고리** 구조로 다시 묶고 각 문제 페이지에 **원문 이미지**를 함께 달아 문제 속 도표·그래프·네트워크 그림을 바로 볼 수 있게 맞췄다.

## 자주 반복되는 영역

| 영역 | 반복 출제 포인트 | 체크 포인트 |
|---|---|---|
| 데이터베이스 | 정규화, 트랜잭션, 회복, 권한 | 함수 종속/이상현상/ACID를 예시와 함께 설명 |
| 네트워크 | TCP 연결, DNS, 라우팅, DHCP, FTP | 계층별 역할과 장애 대응을 구분 |
| 운영체제 | 프로세스·스레드, 메모리, 교착상태, 스케줄링 | 자원관리 관점으로 비교 |
| 보안 | 공개키, ARP/XSS/CSRF, DoS 계열 | 공격 원리 + 방어 조치를 같이 정리 |
| 알고리즘 | MST, 최단경로, 정렬, DP | 시간복잡도와 선택 근거를 같이 답변 |
| 머신러닝/AI | 지도·비지도, K-NN, 경사하강법, RNN | 지표 계산과 한계를 함께 암기 |

## 사용 방법

1. **연도별 분류 허브**에서 회차의 전체 구성부터 본다.
2. 필요한 **하위 카테고리 페이지**로 내려가 문제를 확인한다.
3. 각 문제 페이지 하단의 **원문 이미지**에서 실제 그림·도표를 같이 본다.
4. 계산형은 손으로 다시 풀고, 논술형은 금융기관 운영 맥락까지 붙여 답안화한다.

## 약어 풀이

- CBDC: Central Bank Digital Currency, 중앙은행 디지털화폐
- DB: Database, 데이터베이스
- DNS: Domain Name System, 도메인 이름 시스템
- DP: Dynamic Programming, 동적 계획법
- IT: Information Technology, 정보기술
- TCP: Transmission Control Protocol, 전송 제어 프로토콜
- TLS: Transport Layer Security, 전송 계층 보안
