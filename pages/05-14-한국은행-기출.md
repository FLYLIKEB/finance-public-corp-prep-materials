# 05-14. 한국은행 IT 기출

## G5 IT직군 필기 빈출 영역

한국은행 IT직군은 컴퓨터공학 기본기와 금융IT 이해를 함께 묻는 경향이 강합니다. 공개 복원 자료와 수험생 후기를 기준으로 알고리즘 복잡도, 네트워크, 데이터베이스 트랜잭션, 보안, 지급결제·CBDC 관련 문제가 자주 언급됩니다.

## 대표 유형

| 영역 | 출제 포인트 | 대비 방법 |
|---|---|---|
| 알고리즘 | 시간복잡도, 정렬, 그래프 탐색, DP | Big-O를 코드 조각과 함께 계산 |
| 네트워크 | TCP 연결, TLS, DNS, 라우팅 | 장애 상황을 계층별로 설명 |
| DB | 트랜잭션 격리수준, 인덱스, 정규화 | 동시성·회복 문제와 연결 |
| 운영체제 | 프로세스, 스레드, 메모리, 교착상태 | 자원 관리 관점으로 정리 |
| 금융IT | 지급결제, CBDC, 전자금융 보안 | 한국은행 역할과 연결 |

## 예시 문제

1. B+Tree 인덱스가 범위 검색에 유리한 이유를 설명하시오.
2. TCP 3-way handshake와 TLS handshake의 목적 차이를 설명하시오.
3. 트랜잭션 격리수준이 낮을 때 발생할 수 있는 이상 현상을 예시로 설명하시오.
4. CBDC 도입 시 개인정보 보호와 결제 안정성 측면의 기술 쟁점을 서술하시오.

## 학습 팁

한국은행 답안은 단순 암기보다 “금융 안정성”과 연결하면 강합니다. 예를 들어 DB 트랜잭션 문제도 지급결제 정합성, 네트워크 장애 문제도 금융망 가용성으로 확장해 정리합니다.
