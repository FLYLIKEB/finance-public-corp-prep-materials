# 05-14. 한국은행 IT 기출

## 빠른 길잡이

한국은행 IT직군 기출은 **연도별 흐름**과 **주제별 반복 패턴**을 같이 봐야 효율이 좋다.  
이번 정리는 회차를 그대로 나열하는 대신, **연도 → 하위 카테고리** 구조로 다시 묶고 각 문제 페이지에 **문제 관련 그림**을 붙여 문제 속 도표·그래프·네트워크 그림을 바로 확인할 수 있게 맞췄다.
