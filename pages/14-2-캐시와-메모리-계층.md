# 14-2. 캐시와 메모리 계층

## 메모리 계층 구조

CPU 레지스터에 가까울수록 빠르고 비싸며 용량이 작습니다. 일반적인 계층은 레지스터 → L1 캐시 → L2 캐시 → L3 캐시 → 메인 메모리 → 보조기억장치입니다.

계층 구조의 핵심은 "자주 쓰는 데이터는 비싼 상위 계층에 가까이 둔다"는 것입니다. 따라서 성능 문제를 볼 때는 단순한 CPU 속도보다 hit time, miss rate, miss penalty를 함께 봐야 합니다.

## L1/L2/L3 캐시

| 구분 | 특징 |
|---|---|
| L1 | 코어에 가장 가깝고 매우 빠르며 보통 명령어/데이터 캐시로 분리 |
| L2 | L1보다 크고 느리며 코어 전용인 경우가 많음 |
| L3 | 여러 코어가 공유하는 마지막 레벨 캐시 |

- L1은 지연시간이 가장 짧아 파이프라인 성능에 직접 영향을 준다.
- L2/L3는 용량을 늘려 miss rate를 줄이지만, 상위 계층보다 접근 지연이 길다.
- 멀티코어 환경에서는 공유 L3와 캐시 일관성이 같이 등장하므로 단순 속도 문제를 넘어 데이터 일관성 문제와 연결된다.

## 지역성(Locality)

- 시간 지역성: 최근 사용한 데이터가 다시 사용될 가능성이 높음
- 공간 지역성: 사용한 데이터 주변 주소가 곧 사용될 가능성이 높음

배열 순차 접근이 연결 리스트 무작위 접근보다 빠른 이유는 공간 지역성을 잘 활용하기 때문입니다.

```c
// 행 우선 순회는 보통 캐시 친화적이다.
for (int i = 0; i < N; ++i) {
  for (int j = 0; j < M; ++j) {
    sum += a[i][j];
  }
}
```

실무에서는 루프 교환, 블로킹(tiling), 연속 메모리 배치 같은 방법으로 지역성을 의도적으로 높입니다.

## TLB

TLB는 가상주소를 물리주소로 변환하는 페이지 테이블 항목을 캐시합니다. TLB miss가 많으면 주소 변환 비용이 증가해 성능이 저하됩니다.

- TLB miss는 단순 캐시 miss와 달리 페이지 테이블 탐색 비용까지 유발한다.
- 페이지가 너무 잘게 쪼개져 있으면 TLB pressure가 커질 수 있다.
- huge page는 TLB miss를 줄이는 데 도움이 될 수 있지만 내부 단편화와 관리 비용도 함께 고려해야 한다.

## 금융 IT 연결

대용량 거래 로그 분석, 배치 정산, 리스크 계산에서는 알고리즘 복잡도뿐 아니라 메모리 접근 패턴이 성능을 좌우합니다. 산업은행·금융결제원 필기에서는 캐시 적중률, 지역성, 페이지 교체와 함께 묶어 묻는 경우가 많습니다.

- 컬럼형 데이터 처리나 벡터화 연산은 연속 메모리 접근을 늘려 캐시 효율을 높인다.
- 멀티스레드 서버에서는 false sharing 때문에 캐시 라인 단위 충돌이 발생할 수 있다.
- 프로파일링 시 캐시 miss, TLB miss, 메모리 대역폭 포화 여부를 같이 봐야 원인을 좁힐 수 있다.

## 핵심 개념

- 캐시는 시간 지역성과 공간 지역성을 이용해 평균 메모리 접근 시간을 줄인다. 시간 지역성은 최근 사용한 데이터를 다시 쓸 가능성, 공간 지역성은 가까운 주소를 함께 쓸 가능성이다.
- Direct-mapped cache는 위치가 하나라 빠르지만 충돌이 많고, fully associative는 어디든 배치 가능해 충돌이 적지만 탐색 비용이 크며, set-associative는 둘의 절충이다.
- Write-through는 쓰기를 캐시와 메모리에 동시에 반영해 일관성이 단순하고, write-back은 캐시에만 쓰고 나중에 반영해 성능이 좋지만 dirty bit와 교체 시 반영이 필요하다.
- AMAT는 `Hit Time + Miss Rate × Miss Penalty`로 계산한다. 예를 들어 hit time 1ns, miss rate 5%, miss penalty 100ns이면 AMAT는 `1 + 0.05×100 = 6ns`다.
- TLB는 가상주소 변환 결과를 저장하는 캐시로, 캐시 계층과 함께 실제 메모리 접근 지연에 큰 영향을 준다.

```text
AMAT = Hit Time + Miss Rate × Miss Penalty
```

빠른 암기 포인트

- [ ] compulsory / capacity / conflict miss를 구분할 수 있다.
- [ ] write-through와 write-back의 장단점을 설명할 수 있다.
- [ ] direct-mapped, fully associative, set-associative 차이를 말할 수 있다.
- [ ] TLB miss와 page fault를 다른 현상으로 구분할 수 있다.
