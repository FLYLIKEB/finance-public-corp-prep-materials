### 88. 플립플롭에 대한 설명 중 옳은 것은?
1. SR 플립플롭에서 S=0, R=0인 경우 Q는 무조건 1이 된다.
2. D 플립플롭은 입력 D와 상관없이 항상 동일한 출력을 유지한다.
3. JK 플립플롭에서 J=1, K=1인 경우 Q는 토글 상태가 된다.
4. T 플립플롭에서 T=0인 경우 Q는 1로 설정된다.

  **답:** 3번

- D 플립플롭은 입력 D의 값을 그대로 출력으로 반영합니다.
- T 플립플롭에서 T=0인 경우 출력 Q는 변화하지 않습니다. T=1인 경우에만 Q가 토글됩니다.

### 89. C언어에서 문자열을 비교하는 함수는?
1. strcmp
2. strncmp
3. strcpy
4. strcat

  **답:** 1번
- strncmp: 이 함수는 주어진 길이만큼 두 문자열을 비교합니다. 지정된 길이만큼만 비교하기 때문에 전체
       문자열이 아닌 일부만 비교하고 싶을 때 유용합니다.
- strcpy: 이 함수는 한 문자열을 다른 문자열에 복사하는 함수입니다. 문자열을 비교하는 기능이 아니라,
       문자열을 복사하는 기능을 제공합니다.
- strcat: 이 함수는 한 문자열의 끝에 다른 문자열을 이어붙이는 함수입니다. 문자열을 비교하는 기능이
       아니라, 문자열을 연결하는 기능을 제공합니다.

### 90. 어떤 값보다 큰 가장 작은 정수를 구하는 C언어 함수는?
1. floor
2. ceil
3. round
4. trunc

  **답:** 2번
- floor: 이 함수는 주어진 값보다 작거나 같은 가장 큰 정수를 반환합니다. 예를 들어, floor(3.7)은 3을
       반환합니다.
- round: 이 함수는 주어진 값을 가장 가까운 정수로 반올림합니다. 예를 들어, round(3.5)는 4를,

       round(3.2)는 3을 반환합니다.
- trunc: 이 함수는 주어진 값의 소수 부분을 버리고 정수 부분만 반환합니다. 예를 들어, trunc(3.7)은 3을
       반환합니다.

### 101. 사용자와 데이터원이 위치상 가까이 있어서 좋은 방식은?
1. WAN
2. GAN
3. VPN
4. LAN

  **답:** 4번
- WAN : WAN은 넓은 지역에 걸쳐 데이터를 전달하는 네트워크입니다. 주로 도시, 국가 또는 대륙 간의
        연결에 사용됩니다. 사용자와 데이터원이 물리적으로 가까운 경우에는 적합하지 않습니다.

- VPN : VPN은 공용 네트워크를 통해 프라이빗 네트워크를 구축하는 방식입니다. 보안과 프라이버시를
        제공하지만, 물리적 거리와 상관없이 사용됩니다.

### 122. GAN에 대해 옳지 않은 것은?

  **답:** 2번
