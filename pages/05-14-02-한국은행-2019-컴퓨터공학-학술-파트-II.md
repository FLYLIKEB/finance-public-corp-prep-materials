#### 2.

다음은 RSA 공개키(public key) 알고리즘이다.

```text
1. 2개의 소수 p, q를 선택
2. n = p × q, φ(n) = (p - 1)(q - 1) 계산
3. φ(n)과 서로소인 정수 e 선택 (e와 φ(n)의 최대공약수는 1)
4. e × d를 φ(n)으로 나누었을 때 나머지를 1로 갖는 정수 d 선택
⇒ 공개키(public key) (e, n), 개인키(private key) d
5. 암호화: C = M^e mod n
6. 복호화: M = C^d mod n
```

위에 나타난 동작 알고리즘과 아래의 조건을 참고하여 다음의 물음에 답하시오.

> 주: 조건에 들어가는 구체적인 수치·기호는 현재 공개 추출본에서 판독되지 않아 원본 PDF 확인이 필요함.

2. 메시지를 암호화하여 암호문을 구하시오.
