### 161. 클래스 설계원칙에 대한 바른 설명은?
1. 단일 책임 원칙: 하나의 클래스는 오직 하나의 책임만 가져야 한다.
2. 개방-폐쇄 원칙: 클래스는 확장에는 열려 있어야 하며, 변경에는 닫혀 있어야 한다.
3. 리스코프 교체 원칙: 서브타입은 언제나 자신의 기반 타입으로 교체할 수 있어야 한다.
4. 의존성 역전 원칙: 고수준 모듈은 저수준 모듈에 의존해서는 안 되며, 둘 다 추상화에 의존해야 한다.

### 162. 입력되는 데이터를 컴퓨터의 프로세서가 처리하기 전에 미리 처리하여 프로세서가 처리하는 시간을
줄여주는 프로그램이나 하드웨어를 말하는 것은 무엇인가?
1. EAI (Enterprise Application Integration)
2. FEP (Front-End Processor)
3. GPL (General Public License)
4. Duplexing

  **답:** 2번
- EAI (Enterprise Application Integration): 서로 다른 응용 프로그램 간의 통합을 통해 데이터와
       프로세스를 연결하는 기술입니다.
- GPL (General Public License): 소프트웨어의 자유로운 사용, 수정, 배포를 허용하는 라이선스입니다.
- Duplexing: 데이터 통신에서 양방향으로 동시에 데이터 전송을 가능하게 하는 기술입니다.

### 163. 순수 관계 연산자에서 릴레이션의 일부 속성만 추출하여 중복되는 튜플은 제거한 후 새로운 릴레이션을
생성하는 연산자는 무엇인가?
1. REMOVE
2. PROJECT
3. DIVISION
4. JOIN

  **답:** 2번
- REMOVE: 이는 관계 대수 연산자가 아니며, 질문에서 요구하는 연산과 일치하지 않습니다.
- DIVISION: 릴레이션 연산자 중 하나로, 두 릴레이션 사이의 특정한 조건에 따라 결과를 생성합니다. 주로
       나눗셈 연산의 결과를 얻는 데 사용됩니다.
- JOIN: 두 릴레이션을 결합하여 새로운 릴레이션을 생성하는 연산자입니다. 결합 조건에 따라 튜플을
       연결합니다.

### 164. 병행제어(Concurrency Control) 기법에 해당하지 않는 것은 무엇인가?
1. 로킹기법
2. 최적병행수행 기법
3. 타임스탬프 기법
4. 시분할 기법

  **답:** 4번
- 로킹기법 (Locking Mechanism): 트랜잭션이 데이터에 접근하기 전에 잠금을 설정하여 다른 트랜잭션이
       동시에 동일한 데이터에 접근하지 못하게 하는 기법입니다.
- 최적병행수행 기법 (Optimistic Concurrency Control): 트랜잭션이 충돌 없이 대부분의 시간을 수행할
       것이라고 가정하고, 트랜잭션 종료 시점에 충돌을 검사하여 충돌이 발생하면 롤백하는 기법입니다.
- 타임스탬프 기법 (Timestamp Ordering): 각 트랜잭션에 고유한 타임스탬프를 부여하여 타임스탬프
       순서에 따라 트랜잭션을 처리하는 기법입니다.
