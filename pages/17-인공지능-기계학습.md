# 17. 인공지능·기계학습

한국은행 컴퓨터공학 전공학술에서는 인공지능과 기계학습이 전산학 기본 이론과 금융 데이터 활용 관점에서 연결될 수 있다. 이 장은 최신 트렌드가 아니라 필기 답안에 필요한 기본 개념, 모델, 평가, 위험 관리를 정리한다.

## 핵심 개념

- **AI**는 지능적 행동을 수행하는 시스템 전체를 뜻하고, **Machine Learning**은 데이터로부터 규칙을 학습하는 AI의 하위 분야이며, **Deep Learning**은 다층 신경망을 사용하는 ML의 하위 분야다.
- 지도학습은 정답 라벨이 있는 데이터로 예측 함수를 학습하고, 비지도학습은 라벨 없이 군집이나 차원 구조를 찾으며, 강화학습은 보상 신호를 최대화하는 행동 정책을 학습한다.
- 회귀는 연속값을 예측하고 분류는 범주를 예측한다. 손실함수는 예측과 정답의 차이를 수치화하며, 학습은 손실을 줄이는 방향으로 파라미터를 조정한다.
- 과적합은 훈련 데이터에는 잘 맞지만 새 데이터 성능이 낮은 상태이고, 과소적합은 모델이 너무 단순해 훈련 데이터도 설명하지 못하는 상태다. Bias-variance trade-off는 모델 단순성에서 오는 편향과 데이터 변화에 민감한 분산 사이의 균형이다.

## 학습·검증 절차

| 단계 | 목적 | 주의점 |
| --- | --- | --- |
| Train | 모델 파라미터 학습 | 데이터 누수 방지 |
| Validation | 하이퍼파라미터 선택 | 테스트셋을 반복 사용하지 않음 |
| Test | 최종 일반화 성능 평가 | 학습 종료 후 한 번만 사용 |
| Cross-validation | 데이터가 적을 때 안정적 평가 | fold 간 분포 차이 확인 |

Data leakage는 미래 정보나 정답에 가까운 변수가 학습 과정에 들어가 성능이 과대평가되는 문제다. 금융 데이터에서는 승인 이후에만 알 수 있는 변수, 사후 연체 정보, 전체 데이터로 먼저 정규화한 통계값 등이 누수가 될 수 있다.

## 평가 지표

| 지표 | 의미 | 쓰임 |
| --- | --- | --- |
| Accuracy | 전체 중 맞춘 비율 | 클래스 균형일 때 직관적 |
| Precision | 양성 예측 중 실제 양성 비율 | 오탐 비용이 클 때 중요 |
| Recall | 실제 양성 중 찾아낸 비율 | 미탐 비용이 클 때 중요 |
| F1 | precision과 recall의 조화평균 | 불균형 데이터에서 균형 평가 |
| ROC-AUC | 임계값 변화에 따른 분류 성능 | 순위화 성능 비교 |

Confusion matrix는 TP, FP, FN, TN을 나눠 보여 준다. 이상거래탐지에서는 정상 거래가 훨씬 많으므로 accuracy만 보면 모델이 좋아 보일 수 있어 precision, recall, F1을 함께 봐야 한다.

## 주요 모델

- Linear regression은 선형 관계로 연속값을 예측하고, logistic regression은 sigmoid를 통해 이진 분류 확률을 예측한다.
- Decision tree는 조건 분기로 예측해 해석이 쉽지만 과적합되기 쉽다. Random forest는 여러 트리를 결합해 분산을 줄인다.
- SVM은 margin을 최대화하는 결정경계를 찾고, kernel을 쓰면 비선형 분류도 가능하다.
- K-means는 k개 중심으로 군집을 나누는 비지도학습이고, PCA는 분산을 가장 잘 보존하는 축으로 차원을 줄인다.
- 신경망은 perceptron, activation function, loss, backpropagation, gradient descent로 학습된다. Backpropagation은 출력 오차를 뒤로 전파해 각 가중치의 기울기를 계산한다.

## 금융권 적용과 위험

- 신용평가, 이상거래탐지(FDS), AML 모니터링, 상담 챗봇, 문서 자동분류에 활용될 수 있다.
- 설명가능성(XAI)은 모델 판단 근거를 사람이 이해할 수 있게 하는 요구다. 금융권에서는 소비자 권익, 내부통제, 감독 대응 때문에 중요하다.
- 모델 리스크 관리는 데이터 품질, 편향, 성능 저하, 운영 모니터링, 승인·검증 절차를 포함한다.
- 개인정보와 공정성 문제를 줄이려면 목적 제한, 최소 수집, 비식별/가명처리, 접근통제, 편향 점검을 함께 적용한다.
