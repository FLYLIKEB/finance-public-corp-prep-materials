# 8월: 필기 합격권 진입

> **8월 채용 이벤트**: 한은 서류 접수·마감 가능 / 예탁·예보·주금공·수은 하반기 공고 예상. 기보는 데이터·AI/기술평가 중심이면 비핵심으로 제외한다.

### 8월 일정표

| 날짜 | 채용 이벤트 | 준비 행동 |
|---|---|---|
| 08.01(토) | 기술보증기금 필기 | 데이터·AI/기술평가 중심이면 비응시 또는 낮은 우선순위 |
| 08 초 | 한국은행 G5 서류 접수·마감 가능 | 세부 공고 기준으로 자소서 최종 제출 |
| 08 중순~ | 예탁결제원·예금보험공사·주택금융공사 공고 예상 | 공고 확인, 자소서 빠른 커스터마이징 |
| 08 말 | 산업은행 A매치 공고 예상 | 공고 확인 |

- [ ] 7월 오답 기반 재출제 2회전
- [ ] 한국은행 기출은 회차별 실전 풀이를 9월까지 보류하되, NotebookLM 스타일 기반 유사 문제는 반복
- [ ] 국가직 전산직 7급 기출 소화, 중요 개념은 5급 기출까지 확장
- [ ] 핵심 개념을 5~7문장 서술형 답안으로 작성
- [ ] 오답노트 완성
- [ ] NCS 실전 세트 반복
