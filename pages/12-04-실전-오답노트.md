## 핵심 개념

- 오답 원인은 보통 다음 세 가지로 분류한다: 개념(이론/정의) 부족, 계산·표기 실수(산술/단위/오타 등), 시간 관리 실패(풀다 말고 넘어감 등).
- 각 오답 항목에 대해 재풀이 날짜와 재풀이에 소요된 시간을 반드시 기록한다. 이는 "시간 기반 원인(시간 부족)"인지, "개념 기반 원인"인지 구분하는 핵심 데이터다.
- 동일 유형의 실수가 반복되면 문제 풀이 순서(예: 문제 전체를 먼저 훑고 쉬운 문제부터 풀기), 체크리스트(검산·단위 확인) 또는 풀이 루틴을 수정한다.
- 오답노트는 단순 오답 모음이 아니라, 재발 방지용 작업 문서(작업 지침서)로 운영해야 효과가 있다.

## 쉽게 이해하기

- 오답노트의 목적: 같은 실수를 다시 하지 않도록 "원인 분석 + 재발 방지 조치"를 기록하는 것.
- 기록 항목(권장): 문제번호 / 주제 / 틀린 보기(정답) / 내가 고른 보기 / 틀린 원인(구체적 기술) / 재풀이 날짜 / 재풀이 소요시간 / 개선 액션(예: 개념 요약, 계산 연습, 풀이 순서 변경) / 복습 주기 / 참고 기출 링크.
- 실전 관점: 재풀이 시간 기록을 통해 시간 관리 문제를 식별하고, 모의고사 환경(시간 제한 지켜보기)에서 문제를 다시 풀어본다.

## 오답노트 템플릿(예시)

| 항목 | 설명 |
|---|---|
| 문제번호 | 시험지·문제집 상의 번호(또는 파일명-문항) |
| 주제 | 관련 개념(예: 데이터베이스, 네트워크, 운영체제 등) |
| 틀린 유형 | 개념 / 계산·표기 실수 / 시간 부족 / 해석 오류 등 |
| 내가 고른 답 | 시험 당시 선택한 답 |
| 정답 | 문제의 정답 |
| 원인(자세히) | 왜 틀렸는지 구체적으로 기술(예: "조인 순서와 관계형 연산자 우선순위 혼동") |
| 재풀이 날짜 | 처음 재풀이한 날짜(YYYY-MM-DD) |
| 소요시간 | 재풀이에 걸린 시간(분) |
| 개선 조치 | 취할 행동(예: 개념 노트 작성, 유사문제 5제 추가 풀이, 풀이 순서 변경) |
| 복습 주기 | 다음 복습 예정일(예: D+1, D+3, D+7) |
| 관련 기출 | 관련 기출 문제(상대 링크): [05-금융공기업-IT-기출문제-239제](05-금융공기업-IT-기출문제-239제.md) |

| 틀린 유형 | 개념 부족 |

## 기록·운영 체크리스트

- [ ] 문제를 풀고 바로 오답노트에 입력(당일 기록 권장)
- [ ] 틀린 원인 한 문장으로 요약 + 구체적 근거(왜 그렇게 판단했는지)를 함께 작성
- [ ] 재풀이 날짜와 소요시간 기록
- [ ] 개선 조치(행동)를 정하고, 완료 여부를 체크
- [ ] 동일 유형 3회 반복 시 풀이 순서/전략 수정
- [ ] 주간/월간으로 오답 유형 통계(개념·계산·시간)를 확인해 학습 우선순위 재설정

## 시험 포인트(우선 관리 항목)

- 고빈도 주제 우선: 기출을 통해 자주 출제되는 주제는 오답이 나올 경우 즉시 심화 보강.
- 실수형 문제 관리: 계산·단위 실수는 반드시 풀이 후 체크리스트(계산 검산, 단위 확인)를 추가하여 실수 확률을 낮춘다.
- 시간형 문제 관리: 모의고사 환경에서 문제를 풀 때 재풀이 소요시간을 기록하여 어느 유형에서 시간이 부족한지 파악한다(예: 논리적 해석형에서 시간 부족이면 읽기 전략 개선).
- 반복 유형 식별: 같은 주제에서 반복 오답이 나오면 해당 주제에 대해 요약 노트와 핵심 공식/정리 표를 만든다.

## 실무 연결(학습 → 실무 전환)

- 원인 분석 습관: 오답노트의 "원인 분석"은 실무에서 결함 원인 분석(RCA)이나 장애 분석 시 문제의 본질을 파악하는 역량과 직결된다.
- 재현 가능한 기록: 재현 가능한 재풀이 기록(방법·시간·결과)은 코드 버그 재현 절차나 테스트 케이스 작성 연습에 유용하다.
- 체크리스트 문화: 시험에서의 검산 체크리스트는 실무의 릴리스 체크리스트나 배포 전 점검 항목 구성으로 확장 가능하다.
- 문서화 역량 강화: 오답노트 작성은 짧고 명확한 기술 문서(문제 정의, 원인, 해결책) 작성 연습이 되어 팀 내 지식 공유에 도움이 된다.

## 재풀이 스케줄 예시(권장)

- D+1: 단기 재확인(기억 회복)
- D+3: 초기 고정화 점검
- D+7: 주간 복습(응용 문제로 확인)
- D+30: 장기 복습(유사 문항 풀기)

복습 주기는 개인의 잔여 실력(완전 해결 여부)에 따라 조정한다. 예: 개념 미해결 시 D+1 → D+3 → D+7로 촘촘히, 단순 실수라면 D+7 → D+30으로 확장.
