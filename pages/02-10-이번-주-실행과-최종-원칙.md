# 9. 이번 주 실행: 7/19~7/26

> **이번 주 핵심**: 전 범위 개념 1회 훑기는 끝났다. 이제는 `문제풀이량 부족`을 해결해야 한다. 이번 주는 **전공 직접 풀이량 확보 + 서술형 답안화 + 공고 대기 루틴 고정**이 핵심이다.

## 채용 대응

- [ ] 한국은행 세부 공고 오픈 여부 매일 확인 (apply.bok.or.kr)
- [ ] 공고가 뜨면 문항 차이, 마감일, 제출 서류만 먼저 체크
- [ ] 기보는 데이터·AI/기술평가 중심이면 계속 저우선 또는 비응시 유지

## 전공 직접 풀이 전환

- [ ] OS/DB/네트워크/보안에서 과목당 15문항 이상 직접 풀이
- [ ] 국가직 7급 또는 비한은 금융공기업 기출 10문항 이상 서술형으로 변환
- [ ] 자료구조·알고리즘/SQL은 감 유지 수준이 아니라 **설명 가능한 풀이** 기준으로 정리
- [ ] `맞음 / 애매함 / 틀림 / 모름` 분류표 작성

## 서술형 답안화

- [ ] 5~7문장 답안 12문항 이상 작성
- [ ] 오답 개념 20개 추출
- [ ] 자주 틀리는 개념은 다음 주 NotebookLM 재출제 목록으로 확정
- [ ] 전공논술 1편 또는 전공필기+전공논술 미니 세트 1회 작성

## 유지 과제

- [ ] NCS 1~2세트
- [ ] 프로그래머스 3~5문제 또는 SQL 30문제
- [ ] 작년 한은 자소서 유지/수정 문장 표시
- [ ] 면접 꼬리질문 5개 추가

## 이번 주 완료 기준

- [ ] “개념은 봤지만 문제는 안 풀었다” 상태에서 벗어났는가?
- [ ] 최소 1개 과목은 오답 2회전까지 들어갔는가?
- [ ] 핵심 개념을 말이 아니라 답안 문장으로 써봤는가?
- [ ] 8월부터는 새 개념 확장보다 오답 회전에 집중할 준비가 됐는가?

## 10. 최종 원칙

> **지금은 개념을 더 넓히는 것보다, 이미 본 개념을 시험 답안으로 꺼내는 속도를 올려야 한다.**

> **플래시카드는 약점 확인 보조수단으로만 두고, 하루 학습의 중심은 반드시 문제풀이와 서술형 답안 작성으로 둔다.**

> **한국은행은 전공필기, 전공논술, 일반논술, 자소서 기반 심층면접을 하나의 흐름으로 준비한다.**

> **한국은행 수준으로 전산학을 준비하고, 나머지 금공 IT는 같은 베이스로 흡수한다.**

## 약어 풀이

- DB: Database, 데이터베이스
- IT: Information Technology, 정보기술
- NCS: National Competency Standards, 국가직무능력표준
- OS: Operating System, 운영체제
- SQL: Structured Query Language, 구조화 질의어
