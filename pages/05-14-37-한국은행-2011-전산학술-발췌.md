## 2011 전산학술 발췌

운영체제 동기화, 판매정보 DB, Ajax, RAID, 무선 네트워크/VoIP 시나리오가 한 묶음으로 제시된다.

### I. 운영체제와 데이터베이스

#### 1. 비동기 프로세스와 세마포어

공유 변수 `X`를 여러 비동기 프로세스가 아래처럼 갱신할 때 발생할 수 있는 문제를 설명하고, **세마포어가 어떻게 해결에 쓰일 수 있는지** 묻는다.

```text
Read(X)
X = X + 1
Write(X)
```

#### 2. 판매정보 데이터베이스 SQL

다음 스키마가 주어진다.

- 지점(지점코드, 지점명, 주소, 대표전화)
- 고객(고객코드, 고객명, 연락처, 주소, 우편번호)
- 상품(상품코드, 상품명)
- 거래내역(거래일자, 거래번호, 거래구분, 지점코드, 고객코드, 상품코드, 수량, 거래금액)

질문은 다음과 같다.

- `BS01` 부산지점의 2010년 9월 **일별 판매 현황** 조회 SQL
- 위 질의가 느릴 때 필요한 **인덱스 생성 SQL**
- 2010년 상반기 **상품별 판매수량**을 `OUTER JOIN`으로 구하는 SQL

#### 3. Ajax의 장단점

`Ajax(Asynchronous JavaScript and XML)`의 **장점과 단점**을 간략히 기술하게 한다.

#### 2. 호텔 Wi‑Fi와 인터넷 전화기 시나리오

**2011 전산학술 — 노트북 무선 네트워크 상태 그림**

![2011 전산학술 — 노트북 무선 네트워크 상태 그림](https://raw.githubusercontent.com/FLYLIKEB/finance-public-corp-prep-materials/main/%EC%A4%80%EB%B9%84%EC%9E%90%EB%A3%8C/%ED%95%9C%EA%B5%AD%EC%9D%80%ED%96%89%20%EA%B8%B0%EC%B6%9C/pdf/html/5.%202011%EC%A0%84%EC%82%B0%ED%95%99%EC%88%A0%28%EA%B3%B5%EA%B0%9C%EC%B5%9C%EC%A2%85%29.html/bindata/BIN0002.bmp)


해외 호텔 객실에서

- 노트북은 무선 네트워크 접속 가능
- 인터넷 전화기는 호텔의 웹 인증 페이지를 직접 통과하지 못함

이라는 상황을 주고 다음을 묻는다.

- `AP(Access Point)`의 역할을 **라우터와 비교**하여 설명
- `Wi‑Fi`의 개념, 보안 문제, 해결 기술 설명
- 준비한 장비를 이용해 **인터넷 전화 통화가 가능한 네트워크 구성도**를 제시하고 이유 설명
