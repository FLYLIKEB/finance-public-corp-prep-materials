## 6. DNS

DNS(Domain Name System)는 계층 구조로 분산된 서버들로 구성되어 있고 각 서버에는 자원 레코드(RR, Resource Record)를 저장하고 있다. 각 자원 레코드는 아래와 같이 4개의 필드로 구성된 튜플(Tuple)로 구성되어 있으며 이 정보를 통해 사용자는 원하는 IP 및 기타 정보를 획득할 수 있다.

```text
(Name, Value, Type, TTL)
```

### 가.

DNS 레코드 Type 종류를 3가지 이상 간략히 설명하시오.  
예: AAAA 레코드: 도메인 정보와 IPv6 주소를 저장

### 나.

다음의 그림에서 DNS의 **재귀적 질의(Recursive Query)**와 **반복적 질의(Iterative Query)**의 흐름도를 작성하시오.  
요청 호스트로부터 시작하며 처음 `1번`과 마지막 `8번`은 표시되어 있음.

```text
재귀적 질의(Recursive Query)

요청 호스트 → Local DNS 서버: ①
Local DNS 서버 → Root DNS 서버: ②
Root DNS 서버 → Top Level Domain DNS 서버: ③
Top Level Domain DNS 서버 → Authoritative DNS 서버: ④
Authoritative DNS 서버 → Top Level Domain DNS 서버: ⑤
Top Level Domain DNS 서버 → Root DNS 서버: ⑥
Root DNS 서버 → Local DNS 서버: ⑦
Local DNS 서버 → 요청 호스트: ⑧

반복적 질의(Iterative Query)

요청 호스트 → Local DNS 서버: ①
Local DNS 서버 → Root DNS 서버: ②
Root DNS 서버 → Local DNS 서버: ③
Local DNS 서버 → Top Level Domain DNS 서버: ④
Top Level Domain DNS 서버 → Local DNS 서버: ⑤
Local DNS 서버 → Authoritative DNS 서버: ⑥
Authoritative DNS 서버 → Local DNS 서버: ⑦
Local DNS 서버 → 요청 호스트: ⑧
```
