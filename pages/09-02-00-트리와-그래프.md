# 09-02. 트리와 그래프

> 학습 목적: 계층 구조와 일반 연결 구조의 차이를 구분한다.

## 핵심 개념

- 트리는 사이클이 없는 계층 구조다. (유향/무향 트리 모두 사이클이 없다.)
- 그래프는 정점(vertex)과 간선(edge)으로 구성되는 일반적인 네트워크 구조다.
- 트리는 그래프의 특수한 형태로 볼 수 있다: 연결되어 있고 사이클이 없으며, n개의 정점이 있을 때 간선 수는 항상 n-1이다.

## 주요 용어 정리

- 정점(vertex, node): 그래프/트리의 기본 단위.
- 간선(edge): 정점 간의 연결. 무향(undirected) / 유향(directed) 존재.
- 루트(root): 트리에서 최상위 정점(특정한 루트가 정해진 경우).
- 부모/자식(parent/child), 형제(sibling): 트리에서의 관계 용어.
- 리프(leaf): 자식이 없는 정점.
- 차수(degree): 정점에 연결된 간선의 수.
- 경로(path): 한 정점에서 다른 정점으로 이어지는 간선의 연속.
- 사이클(cycle): 시작 정점으로 되돌아오는 경로(길이 ≥ 1).
- 연결성(connected): 무향 그래프에서 모든 정점이 서로 경로로 연결되어 있는 상태.

## 쉽게 이해하기 — 개념 대비표

- 트리: 조직도, 디렉터리 구조처럼 위아래 계층이 명확.
  - 항상 계층(루트 → 자식) 방향으로 생각할 수 있음
  - 사이클이 없음
  - 정점 수 n → 간선 수 n-1
- 그래프: 지하철 노선도, 네트워크처럼 자유롭게 연결됨
  - 사이클 존재 가능
  - 연결 여부, 방향성, 가중치 등 다양한 특징 보유

## 표현 방법(구현 관점)

- 인접 행렬(Adjacency Matrix)
  - 정점 수가 n일 때 n×n 행렬 사용
  - 간선 존재 여부를 O(1)로 확인 가능
  - 공간 복잡도 O(n^2)
  - 희소 그래프(간선이 적은 경우)에는 비효율적

- 인접 리스트(Adjacency List)
  - 각 정점에 연결된 이웃 목록을 저장
  - 공간 복잡도 O(n + m) (m은 간선 수)
  - 대부분의 실제 그래프에서 효율적

| 표현 방식 | 장점 | 단점 |
|---|---:|---|
| 인접 행렬 | 간선 유무 확인 O(1) | 공간 O(n^2), 희소 그래프 비효율적 |
| 인접 리스트 | 공간 효율적 O(n+m) | 특정 두 정점 간 간선 확인이 O(deg(v)) |

## 탐색 알고리즘(시험에 자주 출제되는 핵심)

- 깊이 우선 탐색(DFS)
  - 동작: 한 경로를 끝까지 내려간 뒤 되돌아와 다른 경로를 탐색
  - 구현: 재귀 또는 스택 사용
  - 시간 복잡도: O(n + m)
  - 용도: 경로 존재 여부, 사이클 검사, 위상 정렬(유향 그래프), 분기 구조 분석

```pseudo
function DFS(node):
  visit(node)
  for each neighbor in adj[node]:
    if not visited[neighbor]:
      DFS(neighbor)
```

- 너비 우선 탐색(BFS)
  - 동작: 루트(또는 시작 정점)에서부터 거리 순서대로 넓게 탐색
  - 구현: 큐 사용
  - 시간 복잡도: O(n + m)
  - 용도: 최단 경로(가중치 없는 그래프), 레벨 순서 탐색

```pseudo
function BFS(start):
  queue = [start]
  visited[start] = true
  while queue not empty:
    node = queue.pop_front()
    for each neighbor in adj[node]:
      if not visited[neighbor]:
        visited[neighbor] = true
        queue.push_back(neighbor)
```

- 트리 특수성: 트리는 사이클이 없으므로 DFS/BFS에서 방문 체크만으로 부모-자식 관계 탐색이 안전하다(부모를 다시 방문하지 않도록 처리).

## 성질과 주의점(시험 포인트)

- 트리 여부 판정(무향 그래프 기준):
  - 연결되어 있고 간선 수가 n-1이면 트리이다.
  - 또는 사이클이 없고 간선 수가 n-1이면 트리이다.
- 루트가 정해진 트리에서는 깊이(depth)와 높이(height)를 구분한다(루트에서의 거리 vs 서브트리의 최대 길이).
- 이진 트리(binary tree): 각 노드가 최대 두 개의 자식을 갖는다. 완전 이진 트리, 포화 이진 트리 등 시험에서 자주 등장하는 개념이다.

## 예제 문제(연습용, 풀이 힌트 포함)

1) 무향 그래프가 주어졌을 때 이것이 트리인지 판정하는 방법을 설명하시오.
   - 힌트: 정점 수 n, 간선 수 m을 확인하고 연결성 및 사이클을 검사한다. (연결 && m == n-1) 이다.

2) 가중치가 없는 그래프에서 두 정점 간 최단 경로를 찾는 방법을 쓰고 시간 복잡도를 서술하시오.
   - 힌트: BFS를 시작 정점에서 실행하면 된다. 시간 복잡도 O(n + m).

3) 인접 리스트로 표현된 그래프에서 특정 간선의 존재 여부를 자주 확인해야 한다. 어떤 표현을 선택해야 효율적인가?
   - 힌트: 간선 존재 여부 확인이 빈번하면 인접 행렬이 O(1)로 유리하지만, 정점 수가 큰 경우 메모리 비용을 고려해야 한다. 문제의 크기와 요구사항을 확인하여 선택한다.
