# 10~11월: 면접 집중

### 목표

- [ ] 한국은행 면접 최우선
- [ ] 타 금융공기업 면접 병행
- [ ] 백엔드 경험 → 금융 IT 답변화
- [ ] 전공 구술 완성

### 답변 구조

```text
개념/상황 → 실무 경험 → 금융공기업 적용 → 리스크 → 대응
```

### 한국은행 면접 유형별 전략

| 면접 | 준비 방향 |
|---|---|
| 토론면접 | 강한 주장보다 합의 도출, 상대 의견 요약·공감·조율 |
| 심층면접 | 자기소개서 기반 꼬리질문 대비, 프로젝트 기술 선택 이유와 문제 해결 과정 정리 |
| 임원면접 | 두괄식·간결한 답변, 여러 지원자 중 차별화되는 핵심 메시지 준비 |

### 한은 면접 키워드

| 키워드 | 연결 방향 |
|---|---|
| 중앙은행 IT | 신뢰 인프라 |
| 지급결제 | 안정성, 무결성 |
| 금융안정 | 장애 예방, 리스크 관리 |
| 데이터 | 정합성, 통계 신뢰성 |
| 보안 | 인증, 접근통제, 감사 |
| 백엔드 경험 | 운영, 장애 대응, API/DB |
