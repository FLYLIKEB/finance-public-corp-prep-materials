## 금융결제원

### 130. 다음 중 스크립트 언어로 올바은 것은?
**답(AI답변):** Python, JavaScript, Ruby 등이 스크립트 언어다. C/C++/Java는 일반적으로 컴파일 언어 성격이 강하다.
### 131. 다음중 DDL에 해당하지 않은 것은?
**답(AI답변):** DDL은 CREATE, ALTER, DROP, TRUNCATE 등이다. SELECT/INSERT/UPDATE/DELETE는 DML이다.
### 132. GPU 특징
**답(AI답변):** GPU는 많은 코어로 병렬 연산에 특화되어 그래픽 처리, AI 학습, 행렬 연산 등에 강하다.
### 133. 직원,부서 테이블 보여주고 관계 관련해서 물어보는 문제
**답(AI답변):** 직원-부서 관계는 보통 부서 1 : 직원 N 관계이며, 직원 테이블이 부서번호를 외래키로 가진다.
### 134. 이진트리에 노드가 80개일때 경로길이
**답(AI답변):** 완전 이진트리 기준 높이는 ⌈log2(80+1)⌉ = 7레벨 정도로 본다. 경로 길이는 문제의 정의(내부/외부 경로 길이)에 따라 계산한다.
### 135. 데이터베이스 릴레이션, 튜플의 특징 문제
**답(AI답변):** 릴레이션은 테이블, 튜플은 행, 애트리뷰트는 열이다. 튜플은 중복되지 않는 것이 관계 모델의 원칙이다.
### 136. (x != 2) && (x != 3)과 동치인것 고르기!
**답(AI답변):** 드모르간 법칙에 의해 !(x == 2 || x == 3)와 동치다.
### 137. risc/cisc
**답(AI답변):** RISC는 단순·고정 길이 명령어와 레지스터 중심, CISC는 복잡·가변 길이 명령어와 메모리 중심 특징이 있다.
### 138. RAID 관련 문제
**답(AI답변):** RAID 0은 스트라이핑(성능, 무중복), RAID 1은 미러링(안정성), RAID 5는 패리티 분산, RAID 6은 이중 패리티다.
### 139. UDP 특징
**답(AI답변):** UDP는 비연결형, 비신뢰성, 순서/재전송 보장 없음, 낮은 오버헤드와 빠른 속도가 특징이다.
### 140. 버퍼오버플로우 관련 문제

   strncpy가 버퍼오버플로우 안나고 strcpy는 버퍼오버플로우 위험 있음
**답(AI답변):** strcpy는 길이 제한이 없어 위험하고, strncpy는 복사 길이를 제한할 수 있어 상대적으로 안전하다.
### 141. 다음 중 정렬알고리즘이 최악인 것을 고르시오
**답(AI답변):** 버블/선택/삽입 정렬의 최악 시간복잡도는 O(n²)이다. 병합/힙은 O(nlogn)이다.
### 142. 다음 정렬알고리즘 중 평균이 다른 것을 고르시오
**답(AI답변):** 퀵/병합/힙은 평균 O(nlogn), 버블/선택/삽입은 평균 O(n²)이므로 다른 복잡도를 고르면 된다.
### 143. Man Month 계산문제
**답(AI답변):** 투입 인원 수 × 투입 개월 수로 계산하는 작업량 단위다.
### 144. TLB 적중률 계산문제
**답(AI답변):** 유효 접근시간(EAT)은 TLB hit/miss 비율을 가중평균해 계산한다. 일반식은 h×hit_time + (1-h)×miss_time 형태다.
### 145. 캐시메모리 적중시간, 적중률 메모리 크기 문제
**답(AI답변):** 평균 접근시간은 hit ratio와 miss penalty를 이용해 AMAT = hit time + miss rate × miss penalty로 계산한다.
### 146. 데이터베이스 관리자 역할은?
**답(AI답변):** DBA는 DB 설계, 권한 관리, 백업/복구, 무결성·보안·성능 관리 역할을 한다.
### 147. 형상관리자 역할은?
**답(AI답변):** 형상관리자는 변경 이력, 버전, 산출물 기준선, 릴리스 구성을 관리한다.
### 148. 인수테스트 뜻
**답(AI답변):** 사용자/고객 관점에서 요구사항 충족 여부를 확인해 시스템 인수 가능성을 판단하는 테스트다.
### 149. 운영체제 기능 문제
**답(AI답변):** 운영체제는 프로세스, 메모리, 파일, 입출력, 장치, 보안, 사용자 인터페이스를 관리한다.
### 150. 시간복잡도 빅오 빠른 순서 객관식 문제

   **답:** N의 제곱, nlogn, n, logn

### 151. SSL특징 문제
**답(AI답변):** SSL/TLS는 전송 계층 보안 프로토콜로 인증, 암호화, 무결성을 제공한다.
### 152. 하노이탑 문제
**답(AI답변):** n개 원반의 최소 이동 횟수는 2^n - 1이며 재귀적으로 n-1개 이동, 큰 원반 이동, n-1개 이동 순서다.
### 153. C언어 파일입출력 틀린 개수 고르기
**답(AI답변):** C 파일 입출력은 fopen, fclose, fscanf/fprintf, fread/fwrite 등을 사용하며 파일 포인터와 모드 지정이 필요하다.
### 154. HTTP 오류 종류 중 틀린 것은?
1. 1xx : 요청을 받았으며 프로세스를 계속한다.
2. 2xx : 요청이 성공적으로 수신되고 처리되었다.
3. 3xx : 클라이언트의 요청에 오류가 있어 서버가 요청을 처리할 수 없다.
4. 4xx : 클라이언트 오류로 인해 요청을 완료할 수 없다.
5. 5xx : 서버 오류로 인해 요청을 처리하지 못했다.

  **답:** 3번
- 3xx 상태 코드는 클라이언트의 요청에 추가 작업이 필요함을 의미하며, 클라이언트의 요청에 오류가
           있는 경우는 4xx 상태 코드에 해당합니다.

### 154. 리눅스 권한 명령어 관련 문제(u(user), g(group), o(others)

  Ex. chmod u+rwx,g+rx,o+r myfile
**답(AI답변):** u는 user, g는 group, o는 others를 뜻한다. chmod u+x처럼 권한을 부여/제거한다.
### 155. (주관식)C언어 코드 출력결과
**답(AI답변):** 문제의 선지/도표가 원문에 충분히 남아 있지 않아 단정형 정답은 제한적이다. 해당 주제의 핵심 개념과 대표 공식·특징을 기준으로 풀이해야 한다.
### 156. (주관식)그래프 전위순회 경로를 적으세요
**답(AI답변):** 전위순회는 루트(시작 정점)를 먼저 방문한 뒤 왼쪽/인접 하위 노드를 재귀적으로 방문하는 순서다.
### 157. (주관식)SQL 문제 약술 - REVOKE, GRANT
**답(AI답변):** GRANT는 권한 부여, REVOKE는 권한 회수 명령이다.
