# 14-3. 명령어 세트

## ISA의 의미

명령어 세트 아키텍처(ISA)는 하드웨어와 소프트웨어 사이의 약속입니다. CPU가 이해하는 명령어, 레지스터, 주소 지정 방식, 데이터 형식을 정의합니다.
![명령어 세트 구조](https://raw.githubusercontent.com/FLYLIKEB/finance-public-corp-prep-materials/main/assets/downloaded-visual-aids/risc-v-logo.svg)
> 그림: RISC 계열 명령어 집합 예시 기반으로 명령어 세트 구조 개념을 시각적으로 확인한다.
> 출처: https://commons.wikimedia.org/wiki/File:RISC-V-logo.svg

ISA는 단순히 "명령어 목록"이 아니라 다음을 함께 규정하는 계약으로 이해하면 좋습니다.

- 어떤 연산이 가능한가
- 피연산자를 어디서 읽고 어디에 저장하는가
- 예외·인터럽트가 발생했을 때 어떤 규칙으로 복귀하는가
- 컴파일러와 운영체제가 어떤 전제를 두고 코드를 생성하는가

## RISC vs CISC

| 구분 | RISC | CISC |
|---|---|---|
| 명령어 | 단순하고 길이가 비교적 일정 | 복잡하고 다양한 길이 |
| 실행 | 파이프라인에 유리 | 명령 하나가 많은 일을 수행 |
| 예 | ARM, RISC-V | x86 계열 |
| 장점 | 전력 효율, 단순한 제어 | 코드 밀도, 하위 호환성 |

RISC가 항상 빠르고 CISC가 항상 느린 것은 아닙니다. 현대 CPU는 내부적으로 복잡한 명령을 마이크로 연산으로 변환해 실행하기도 합니다.

- RISC는 보통 load/store 구조와 고정 길이 명령어를 사용해 파이프라인 제어가 단순하다.
- CISC는 코드 밀도와 하위 호환성 측면에서 강점이 있지만 디코딩과 내부 제어가 복잡해질 수 있다.
- 시험에서는 "전력 효율·파이프라인 친화성" 대 "코드 밀도·호환성" 구도로 정리하면 안정적이다.

## 어드레싱 모드

- 즉시 주소 지정: 명령어 안에 상수 값 포함
- 직접 주소 지정: 명령어가 메모리 주소를 직접 지정
- 간접 주소 지정: 지정된 주소에 실제 주소가 저장
- 레지스터 주소 지정: 레지스터에 피연산자 저장
- 인덱스 주소 지정: 기준 주소와 인덱스를 더해 접근

예시로 보면 차이가 더 잘 보입니다.

```text
ADD r1, r2, #10     ; 즉시 주소 지정
LD  r1, [1000]      ; 직접 주소 지정
LD  r1, [r2]        ; 간접/레지스터 간접 주소 지정
LD  r1, [r2 + 8]    ; 베이스+오프셋(인덱스) 주소 지정
```

주소 지정 방식은 메모리 접근 횟수와 주소 계산 비용을 바꾸므로, 단순 정의보다 "어떤 방식이 더 빠르고 왜 그런가"를 같이 생각해야 합니다.

## 기출 포인트

어드레싱 모드는 주소 계산 방식과 메모리 접근 횟수를 묻는 문제가 많습니다. RISC/CISC 비교는 단순 암기보다 파이프라인·전력·호환성 관점으로 정리해야 합니다.

- 즉시·레지스터 주소 지정은 추가 메모리 접근이 없다는 점이 자주 출제된다.
- 베이스+오프셋 방식은 배열, 스택 프레임, 구조체 필드 접근 설명에서 자주 등장한다.
- SIMD/MIMD와 Amdahl의 법칙은 병렬 처리 파트와 연결해 짧은 계산 문제로 나오기 쉽다.

## 핵심 개념

- ISA는 하드웨어가 이해하는 명령어, 레지스터, 주소지정 방식, 데이터 형식을 정의하는 소프트웨어와 하드웨어의 계약이다.
- RISC는 단순하고 고정 길이 명령어, load/store 구조, 많은 레지스터를 통해 파이프라이닝에 유리하다. CISC는 복잡한 명령어로 코드 밀도를 높일 수 있지만 디코딩과 파이프라인 제어가 복잡하다.
- 주소지정 방식에는 즉시, 레지스터, 직접, 간접, 베이스+오프셋 방식이 있다. 배열 접근과 스택 프레임 설명에서는 베이스 레지스터와 오프셋 개념이 자주 쓰인다.
- SIMD는 하나의 명령으로 여러 데이터에 같은 연산을 적용해 벡터·행렬 처리에 유리하고, MIMD는 여러 프로세서가 서로 다른 명령과 데이터를 처리하는 일반적인 멀티코어 구조다. Amdahl's law는 병렬화되지 않는 부분이 전체 속도 향상의 상한을 정한다.

```text
Speedup = 1 / ((1 - P) + P / N)
```

- 여기서 `P`는 병렬화 가능한 비율, `N`은 프로세서 수다.
- 실무에서는 동기화 오버헤드와 캐시 일관성 비용 때문에 이론값보다 낮게 나온다.

빠른 복습 체크포인트

- [ ] ISA가 정의하는 항목을 3가지 이상 말할 수 있다.
- [ ] RISC/CISC 차이를 성능·전력·호환성으로 설명할 수 있다.
- [ ] 주소 지정 방식별 메모리 접근 여부를 구분할 수 있다.
- [ ] SIMD/MIMD와 Amdahl의 법칙을 병렬 처리 문맥으로 설명할 수 있다.

## 약어 풀이

- CISC: Complex Instruction Set Computer, 복합 명령어 집합 컴퓨터
- RISC: Reduced Instruction Set Computer, 축소 명령어 집합 컴퓨터
- ISA: Instruction Set Architecture, 명령어 세트 아키텍처
- SIMD: Single Instruction, Multiple Data, 하나의 명령으로 여러 데이터 처리
- MIMD: Multiple Instruction, Multiple Data, 여러 명령과 여러 데이터 처리
