# Wikidocs 금융공기업 준비 목차 재구성 설계

작성일: 2026-06-08

## 목표

금융공기업 IT 필기 학습 자료를 현재의 큰 단원 중심 구조에서 과목별 2~3단계 학습 구조로 확장한다. 학습자는 06~13 과목 페이지에서 바로 핵심 개념, 빈출 포인트, 기출 연결, 오답 포인트를 확인할 수 있어야 한다.

## 범위

이번 작업은 다음 네 가지를 포함한다.

1. `TOC.md`에서 06~13 과목별 목차를 2~3단계로 확장한다.
2. 새로 추가되는 세부 페이지를 생성하고 공통 학습 템플릿을 삽입한다.
3. 기존 04 IT 필기 핵심정리의 관련 내용을 과목별 페이지에 요약 또는 참조 형태로 연결한다.
4. 05 기출문제는 기관별 원본을 유지하고, 주제별 색인 페이지를 추가한다.

## 비범위

- 기존 04 원문 페이지를 삭제하지 않는다.
- 기존 05-1~05-8 기관별 기출 페이지를 대량 편집하거나 문항 순서를 바꾸지 않는다.
- 모든 04 내용을 완전 이관하지 않는다. 이번 단계에서는 학습 동선을 만드는 것이 목적이다.

## 권장 접근

기존 자료 손실을 막기 위해 “구조 먼저 + 템플릿 + 최소 이관” 방식으로 진행한다.

- 06~13 과목별 세부 목차를 추가한다.
- 새 페이지에는 공통 학습 템플릿을 넣는다.
- 04 내용은 삭제/분해하지 않고, 관련 세부 페이지에서 요약 및 출처 참조로 연결한다.
- 05는 주제별 색인을 추가해 복습 효율을 높인다.

## 새 페이지 템플릿

새로 생성되는 학습 페이지는 다음 구조를 사용한다.

```markdown
# 번호. 제목

> 학습 목적: 이 페이지에서 반드시 익힐 내용을 한 문장으로 정리한다.
> 관련 기출: 연결되는 기관별 기출 또는 주제별 색인을 적는다.
> 연결 핵심정리: 관련 04 핵심정리 페이지 또는 섹션을 적는다.

## 핵심 개념

## 빈출 포인트

## 기출 연결

## 오답 포인트

## 빠른 점검
```

상위 과목 페이지는 세부 페이지 목록과 학습 순서를 안내한다. 세부 페이지는 실제 학습 내용을 담는 단위로 사용한다.

## 04 핵심정리 연결 방식

04 원문은 보존한다. 대신 다음처럼 관련 과목 페이지에 연결한다.

- 04-3의 프로세스 스케줄링, 단편화, 페이징, 교착상태는 06 운영체제 하위 페이지로 연결한다.
- 04-3의 비용산정모델은 11-4 형상관리와 비용산정에 연결한다.
- 04-4의 프로토콜, TCP/UDP, TLS, 공격 기법은 08 네트워크와 10 보안에 연결한다.
- 04-5의 트리, 정렬, 데이터베이스, NoSQL, 금융IT는 07 데이터베이스, 09 자료구조/알고리즘, 13 SQL/코딩에 연결한다.

페이지 본문에는 원문 전체를 복사하기보다 핵심 요약, 출제경향, 원문 참조 링크를 우선 넣는다. 필요한 경우 짧은 정의나 비교표만 복제한다.

각 색인 페이지는 문항 전체를 반복하지 않고 다음 형식을 사용한다.

```markdown
| 기관 | 문항 | 키워드 | 복습 위치 |
|---|---:|---|---|
| 우리은행 | 23 | VPN | 08-3 HTTP-DNS-TLS / 10-2 인증-인가-접근통제 |
```

## 검증 기준

작업 후 다음을 확인한다.

1. `TOC.md`의 모든 링크 대상 파일이 존재한다.
2. 테스트용 01-1-1 페이지는 재생성하지 않는다.
3. 06~13 과목 페이지와 새 하위 페이지에 공통 템플릿 또는 학습 안내가 들어 있다.
4. 05-9~05-13 색인 페이지가 존재하고 TOC에 연결되어 있다.
5. 기존 04, 05 기관별 원문 페이지는 보존된다.
6. git diff에서 삭제/이동보다 추가와 구조화가 중심인지 확인한다.

## 구현 순서

1. 새 페이지 목록을 확정하고 파일명을 생성한다.
2. `TOC.md`에 06~13 하위 목차와 05 주제별 색인을 추가한다.
3. 새 페이지에 템플릿과 가능한 핵심 요약을 삽입한다.
4. 04 핵심정리 관련 링크를 새 페이지에 반영한다.
5. 05 기관별 문항에서 명확한 주제 문항을 추려 색인 페이지에 기록한다.
6. 링크 검증 스크립트로 누락 파일을 확인한다.
7. 변경사항을 커밋하고 푸시한다.
