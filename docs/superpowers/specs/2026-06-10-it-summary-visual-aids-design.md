## 렌더링 제약

- Wikidocs에서 깨질 수 있는 Mermaid, 외부 이미지, 로컬 `.md` 상대 링크는 사용하지 않는다.
- 표준 Markdown 표와 코드블록 기반 ASCII 다이어그램을 사용한다.
- 기존 원문은 삭제하지 않고, 개념 설명 뒤에 `비교표`, `흐름도`, `계산 예시`, `암기 포인트`를 추가한다.
- 모바일 폭에서도 읽히도록 표는 핵심 항목 위주로 압축한다.

## 보강 유형

### 비교표

헷갈리는 개념을 기출 선지 판단 기준으로 정리한다.

예상 항목:

- 3V/5V/7V
- 정형/반정형/비정형 데이터
- 퍼블릭/프라이빗 블록체인
- PoW/PoS
- 지도/비지도/강화학습
- 스크립트/컴파일 언어
- 오버로딩/오버라이딩
- DDL/DML/DCL
- IaaS/PaaS/SaaS
- 퍼블릭/프라이빗/하이브리드 클라우드
- CPU/GPU
- RAM/ROM
- RISC/CISC
- IPv4/IPv6
- 대칭키/공개키
- VM/컨테이너
- 정렬 알고리즘 시간복잡도
- 정규화 단계

구조나 흐름을 코드블록으로 표현한다.

예상 항목:

- 빅데이터 분석 방법론 흐름
- 블록체인 블록 연결 구조
- 분산처리시스템 구조
- 클라우드 서비스 모델 계층
- 프로세스 스케줄링 Gantt 예시
- 2PL 확장/축소 단계
- 내부/외부 단편화
- 페이징/세그먼트
- 공개키 암호화 흐름
- 트리 순회 예시
- VM vs 컨테이너 구조

## 검증 계획

- 대상 Markdown 파일에 Mermaid 코드블록, 외부 이미지 링크, 로컬 `.md` 링크를 새로 추가하지 않았는지 확인한다.
- 표 문법이 깨지지 않았는지 `| --- |` 구분 행을 확인한다.
- 코드블록 fence 개수가 짝수인지 확인한다.
- `git diff --check`로 공백 오류를 확인한다.
- 변경 내용을 커밋하고 원격 브랜치에 푸시한다.
